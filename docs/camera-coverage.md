# 9대 카메라 관측 범위 시안

2026-10-13 사용자는 **9대의 추정 방향·화각·표시 거리를 조정하는 시안**을 먼저 구현하도록 선택했습니다.
지도 상단 **관측 범위**에서 카메라별 수평 부채꼴을 함께 표시합니다.
실시간 PTZ를 수신하거나 영상에서 방향을 자동으로 계산하는 기능은 아닙니다.

1. 카메라 목록에서 조정할 카메라를 선택합니다.
2. **범위 방위각(°)**을 직접 입력합니다. 북=0°, 동=90°입니다.
3. **범위 수평 화각(°)**과 **범위 표시 거리(m)**를 조정하고 **입력값으로 범위 시안 표시**를 누릅니다.
4. 표시한 시안의 슬라이더를 움직이면 해당 카메라의 부채꼴이 바로 바뀝니다. 숫자 입력은 표시 버튼으로 반영합니다.
5. 다른 카메라도 같은 방법으로 설정하면 각기 다른 색으로 동시에 표시합니다.
   범위나 카메라 마커를 클릭하여 선택할 수 있습니다. **선택한 카메라 범위만 보기**, 개별 체크박스,
   **범위 시안 전체 표시**와 **전체 범위 시안 보기**로 비교합니다.

방향은 초기 미입력 상태입니다. UNKNOWN 방향을 북쪽으로 채우거나 임의의 9대 방향을 기본 배포하지 않습니다.
초기 화각 60°와 표시 거리 1000m는 편집용 시안 값이며 실제 카메라 화각/최대 관측 거리로 확정하지 않습니다.
값을 입력하지 않은 카메라는 **범위 미설정**으로 남기며 기존 위치 마커는 계속 표시합니다.

## 영상 보정값과 유효성

기존 [영상·지형 보정](terrain-calibration.md)의 `manual-calibration / estimate / unvalidated` 방향·화각이 있으면
**저장된 보정값으로 범위 표시**로 재사용할 수 있습니다. 표시 거리는 여전히 별도 시안 값입니다.
기준 영상에 대한 추정이며 현재 방향을 관측했다는 의미가 아닙니다.
위치가 바뀌면 이전 시안을 숨깁니다. 영상 보정값으로 만든 시안은 보정이 바뀌거나 stale/삭제되면 숨기고 재설정을 요구합니다.
사용자가 별도로 입력한 수동 시안은 영상 보정과 별개이며 회전/줌 변경 후 직접 다시 조정해야 합니다.
자동 회전/줌 변화 탐지와 시안 만료는 구현하지 않았습니다.

가상 시점 보정 중에는 모든 범위 시안을 숨겨 영상·지형 비교를 가리지 않습니다.
일반 지도 보기로 돌아오면 다시 표시합니다. 관측 범위 시안이 있는 선택 카메라의 기존 단일 시험 부채꼴은 중복 표시하지 않습니다.

## 저장과 공유

범위 시안은 기본적으로 브라우저 메모리에만 있습니다. **범위 시안 보관 → 이 브라우저에 범위 시안 저장**을
직접 누르면 localStorage에 저장하고 같은 사이트를 다시 열 때 불러옵니다. 자동 저장/서버 업로드는 없습니다.
브라우저 저장이 막히면 **범위 시안 다운로드**로 보관합니다. 다른 PC에서는 받은 JSON을 선택하여 불러올 수 있습니다.
**저장된 범위 시안 지우기**는 저장 파일과 현재 시안을 제거합니다.

JSON은 `kind=coverage-preview`, `confidence=unvalidated`이며 고유 카메라 ID, 위치 스냅샷,
입력 각도·거리, 표시 여부·입력 시각과 출처를 담습니다. 영상 보정 재사용 시에는 근거 변경 확인용 토큰도 포함합니다.
지도 키, SSM 계정/주소, 원본 이미지는 포함하지 않습니다. 이 파일은 지도 좌표/보정 설정과 별도이며 중앙 Bridge에는 저장하지 않습니다.
현재 공개 기본 지도에는 이름·좌표와 경계/탐방로만 포함합니다. 사용자가 입력한 범위 시안을 공개 코드로 전송하지 않습니다.

## 표현과 검증 한계

방위각 0~359.999999°, 수평 화각 5~120°, 표시 거리 10~20,000m를 검증합니다.
지구 구면에서 표시 거리와 각도로 부채꼴을 계산하고 Cesium 폴리곤·경계선·중앙선으로 그립니다.
지원되는 뷰어에서는 지형과 3D 타일에 붙이며, 지도 표면에 붙이는 처리는 산 뒤의 비가시 구간을 계산하는 처리가 아닙니다.
고도·Tilt·수직 화각·렌즈 모델·DEM 차폐·가시선·실제 거리별 해상도를 계산하지 않습니다.
부채꼴 안이라고 해서 실제 영상에 보이거나 관측 가능한 장소로 판정하지 않습니다.

자동 검사는 모의 SDK로 9대 동시 표시, 선택/숨김, 반경, 좌표 변경/보정 무효화, 명시적 저장/복원,
파일 검사와 기존 지도 레이어 유지 및 보정 중 숨김을 확인합니다. 실제 VWorld 지형 표출과 방향 정확도는 별도 현장 확인이 필요합니다.
카메라 명령이나 장치 연결 요청을 추가하지 않습니다. 다음 단계는 한 대의 영상·지형을 맞추고 기준점으로 방향·화각을 검증하는 것입니다.
