# 지도에서 선택한 위치의 지번 조회

지도 상단 **위치·지번 → 지도에서 위치 선택**을 켜고 확인할 지형 지점을 클릭합니다.
선택 지점의 위도·경도와 VWorld에서 반환한 지번 주소를 표시합니다. **좌표·지번 복사**로
신고·상황 공유에 사용할 참고 문구를 복사할 수 있습니다. **위치 선택 종료**를 누르면
지도 마커를 눌러 카메라를 선택하는 기존 동작으로 돌아갑니다.

좌표를 알고 있다면 **좌표 직접 입력 (선택)**에서도 조회할 수 있습니다.
선택 지점은 화면에서만 유지하고 카메라 설치 위치·방향·관측 범위 설정에 저장하지 않습니다.
별도 화재 기록 생성이나 CCTV 제어는 하지 않습니다.

## 키와 조회 방식

연결에 실제 적용한 VWorld 키를 재사용합니다. GitHub Actions의 `VWORLD_API_KEY`로 자동 연결했다면
다시 입력할 필요가 없습니다. 직접 다른 키로 연결했다면 그 키로 주소를 조회합니다.
VWorld 키 관리에서 **Geocoder API(주소·좌표 변환)** 사용 설정과 실제 서비스 URL
`https://hyeonbae-jeon.github.io/fire-monitoring/` 허용을 확인해야 합니다.
지도·검색 API의 사용 설정만으로 Geocoder 권한이 확인되지는 않습니다.

브라우저에서 VWorld의 `https://api.vworld.kr/req/address`에 읽기 전용 역지오코딩 요청을 보냅니다.
`service=address`, `request=getAddress`, `crs=EPSG:4326`, `point=경도,위도`, `type=PARCEL`,
`format=json`을 사용하고 JSONP callback으로 응답을 받습니다. 등록 사이트는 실제 앱 주소를 전달합니다.
주소 요청에는 선택 좌표와 브라우저용 키만 보내며 장비 IP·UUID·계정·CCTV 이미지는 보내지 않습니다.
제삼자 프록시는 사용하지 않습니다. 키는 화면·복사 문구·로컬 저장에 포함하지 않습니다.

반환된 `response.result` 중 `type=parcel`의 `text`만 지번 주소로 표시합니다.
도로명 결과를 지번으로 대체하거나 없는 주소·지번·필지 번호를 추측하지 않습니다.
주소 없음, 오류, 10초 시간 초과에도 선택한 좌표는 남습니다. 재조회할 수 있습니다.
새 지점을 고르면 이전 요청을 취소하고 늦게 도착한 응답을 무시합니다.

## 위치 선택의 의미

3D 화면의 보이는 표면을 Cesium 깊이 조회로 선택합니다. 자체 카메라 마커·범위 시안·경계·탐방로를
잠깐 숨긴 상태로 다시 렌더링하여 표시 도형이 지형 높이로 선택되지 않게 합니다.
깊이 조회를 지원하지 않을 때는 확인된 비타원체 지형 공급자의 ray 조회만 사용합니다.
하늘·미로딩 지형·지원 불가에서 임의 좌표나 평면 지면을 선택하지 않고 다시 선택하도록 안내합니다.
지도 높이는 지도 표면의 참고 높이이며 실측 설치 높이·화재 고도가 아닙니다.
VWorld의 건물·기타 3D 표면이 있는 곳에서는 그 보이는 표면이 선택될 수 있습니다.

**지도에서 찍은 지점이 실제 화재 위치인지는 별도로 확인해야 합니다.**
CCTV에서 연기가 보이는 픽셀만으로 실제 지상 발화점을 자동 계산하는 기능은 아직 없습니다.
특히 연기가 상승하거나 다른 능선 뒤에서 발생하면 보이는 연기와 지상 위치가 다를 수 있습니다.
회전·줌이 바뀐 뒤 기존 영상 보정값을 현재 방향으로 확정할 수 없습니다.

조회 지번은 선택 좌표의 참고 주소입니다. 필지 경계·토지 소유자 조회나 법적 경계 확정은 포함하지 않습니다.
현장 위치 파악에는 좌표·탐방로·지형 대조를 함께 사용합니다.

## 확인 근거와 남은 검증 (2026-10-13)

- 공식 [V-world/V-QGIS API client](https://github.com/V-world/V-QGIS/blob/master/utils/api_client.py)의
  `reverse_geocode`에서 `/req/address`, `getAddress`, `EPSG:4326`, `point=x,y` 요청을 확인했습니다.
- 공식 [VWorld 교육 예제](https://github.com/V-world/V-world_API_sample/tree/master/%EB%B8%8C%EC%9D%B4%EC%9B%94%EB%93%9C_%EA%B5%90%EC%9C%A1/2026%EB%85%84_%EB%B8%8C%EC%9D%B4%EC%9B%94%EB%93%9C_%EA%B5%90%EC%9C%A1)의
  Geocoder 주소 API와 `PARCEL` 유형 사용을 확인했습니다. 예제의 키 값은 사용하지 않습니다.
- [공식 역지오코딩 안내](https://www.vworld.kr/dev/v4dv_geocoderguide2_s002.do)와
  주소 API는 이 클라우드의 직접 접속 시험에서 HTTP 503을 반환했습니다. 원인은 미확인입니다.
- 합성 SDK/주소 응답으로 좌표 순서·지번 결과 구분·오류·시간 초과·늦은 응답 무시·카메라 선택 복귀를 검증합니다.
  실제 VWorld JSONP 응답, 운영 키의 Geocoder 권한, 실제 지형 클릭·지번 일치는 사용자 PC에서 추가 확인해야 합니다.

실사이트 확인: 지형이 잘 보이는 곳을 선택하고 좌표와 지번이 나오는지 확인합니다.
주소가 나오지 않으면 화면 안내와 오류 여부를 전달합니다. 키 값이나 키가 포함된 요청 URL은 전달하지 않습니다.
