# 지형 가림 계산 시안

2026-10-13 사용자가 산에 가리는 구간 반영을 요청하고, 실제 설치 높이는 미확인인 상태에서
**지면에서 렌즈까지 3m**를 시험값으로 지정했습니다. 새 가상 시점과 지형 가림 계산의 초기 높이를 3m로 사용합니다.
기존에 저장한 영상 보정의 높이는 해당 보정값으로 유지하고, 지형 가림에서는 별도로 선택해 적용할 수 있습니다.
3m를 실측값으로 기록하거나 현재 PTZ 방향으로 확정하지 않습니다.

## 사용

1. 지도 상단 **관측 범위**에서 카메라를 선택합니다.
2. 방위각·수평 화각·표시 거리를 입력하고 **입력값으로 범위 시안 표시**를 누릅니다.
3. 아래 **산에 가리는 구간 · 계산 시안**에서 시험 렌즈 높이 3m를 확인합니다.
4. **선택 카메라 지형 가림 계산**을 누릅니다. 50m 또는 100m 높이 표본 간격을 선택할 수 있습니다.
5. 초록 **비가림 추정**, 빨강 **가림 추정**, 노랑 **미확인·경계**를 대조합니다.
   여러 카메라를 한 대씩 계산하면 유효한 결과를 함께 표시합니다. **선택한 카메라 범위만 보기**로 분리할 수 있습니다.

최초 시안은 표시 거리 **5,000m 이내**, 수평 방향 **24구간**으로 제한합니다.
더 먼 범위를 설정하면 자동으로 잘라서 계산하지 않고, 표시 거리를 줄이도록 안내합니다.
계산 중 진행 수를 표시하며 중지할 수 있습니다. 높이 조회 90초 시간 초과는 오류로 표시합니다.
일반 지도 보기에서 계산합니다. 가상 시점 보정 중에는 범위·가림 시안을 함께 숨기고 돌아오면 다시 표시합니다.

카메라 설치 좌표, 방향·화각·거리, 보정 근거, 렌즈 높이 또는 표본 간격을 바꾸면 관련 결과를 숨기고 재계산합니다.
회전·줌은 실시간으로 수신하지 않으므로 운영자가 범위 시안을 직접 갱신해야 합니다.
지도 재연결 시 계산 결과를 지웁니다. 결과와 시험 높이 입력은 브라우저 메모리에만 유지하고 서버/공개 소스에 저장하지 않습니다.
기존 **범위 시안 보관**은 방향·화각·거리만 보관하며 지형 가림 계산 결과는 포함하지 않습니다.

## 높이 조회

지도에 이미 연결된 SDK를 사용하여 동일한 높이 출처에서 설치 지점과 방위별 거리 표본을 읽습니다.
추가 카메라 접속·CCTV 이동 명령·계정 조회는 없습니다. 지도 지형/3D 타일을 읽는 요청만 발생할 수 있습니다.

- 확인된 비타원체 지형 공급자와 availability가 있으면 `Cesium.sampleTerrainMostDetailed`를 사용합니다.
- 그렇지 않고 지원되면 `scene.clampToHeightMostDetailed`로 3D 표면을 조회합니다.
- 상세 조회가 없을 때는 `scene.clampToHeight`의 현재 화면에 로딩된 표면을 사용하고 그 출처를 표시합니다.

각 묶음은 최대 64지점이며 전체 표본은 제한합니다. 자체 카메라 마커·범위·지번 선택점·경계·탐방로·가림 시안을
조회 대상에서 제외합니다. 비동기 조회 중 자체 도형이 바뀌면 해당 묶음을 버리고 다시 읽습니다.
취소·입력 변경·연결 교체 후 도착한 응답은 적용하지 않습니다.

읽지 못한 높이는 `null`로 유지합니다. 장면 조회의 0m 근처 값은 평면 타원체와 구분할 근거가 부족하여 미확인으로 처리합니다.
확인된 지형 공급자의 정상 0m 값은 사용할 수 있습니다. 설치 지점 높이가 없으면 전체 계산을 보류합니다.
사용자가 입력한 해발고도나 보정용 지면 높이를 다른 지도 출처와 임의로 섞지 않습니다.
표시 높이는 지도 표면의 참고값이며 실제 지면·측량 높이 또는 나무/건물을 제거한 DEM임을 보증하지 않습니다.

## 가시선과 표현

지도 표면 높이에 렌즈 시험 높이를 더해 관측점을 정하고, 각 방위의 가까운 표본부터 먼 표본까지
관측점에서의 고도각을 비교합니다. 지구 구면 곡률을 반영하며 대기 굴절은 적용하지 않습니다.
앞 능선보다 낮은 골짜기는 가림으로 분류할 수 있고, 더 높은 먼 봉우리는 다시 비가림으로 분류할 수 있습니다.
처음 가려진 거리에서 전체 범위를 잘라내는 방법을 사용하지 않습니다.

중간 높이가 없으면 이후의 비가림 여부도 미확인으로 남깁니다. 다만 이미 읽은 능선에 가리는 표본은
가림으로 분류할 수 있습니다. 네 모서리의 분류가 다른 경계 격자는 노랑으로 남겨 가림 경계를 확정하지 않습니다.
같은 분류로 이어진 거리 구간을 합쳐 그리며, 계산된 카메라의 기존 단색 부채꼴 채우기는 제거하고 경계선은 유지합니다.
범위 전체·카메라별 표시와 선택한 카메라만 보기 설정이 계산 결과에도 적용됩니다. 경계·탐방로 레이어는 함께 유지합니다.
표시 비율은 표본 격자의 수평 면적 비율이며 카메라 영상에서 보이는 픽셀 비율이 아닙니다.

**이 결과는 수평 범위 안의 지도 표면 가시선 시안입니다.**
실제 Tilt·수직 화각·광학 렌즈·영상 해상도와 현재 PTZ가 반영된 촬영 가능 영역으로 확정할 수 없습니다.
표본 사이의 좁은 능선, 지형 해상도/높이 오차, 나무·건물·기상은 추가 검증 대상입니다.
지면이 가려져도 솟아오른 연기는 보일 수 있으므로 화재 위치 판단은 CCTV·지형·현장 정보와 대조해야 합니다.

## 검증 상태

높이 함수의 의미는 [Cesium Scene 공식 소스](https://github.com/CesiumGS/cesium/blob/main/packages/engine/Source/Scene/Scene.js)의
`clampToHeight` / `clampToHeightMostDetailed` 명세로 확인했습니다. 지원 여부를 실제 SDK에서 검사합니다.
사용자 환경에서 VWorld 지도가 보인다는 확인은 있지만, 현재의 높이 조회·지도 정합·차폐 정확도는 아직 현장 검증 전입니다.

합성 높이 자료로 앞 능선/골짜기/높은 먼 봉우리, 렌즈 높이 변화, 곡률, 누락 구간, 정상 0m 지형 공급자,
입력 무효화, 오버레이 제외/변경, 취소·시간 초과, 여러 카메라/레이어와의 공존을 자동 검증합니다.
합성 SDK 검사를 실지도 정확도 검증으로 취급하지 않습니다.

현장에서는 한 대의 화면을 먼저 맞추고, 실제로 보이는 능선/가려진 골짜기 기준점과 색상 분류를 비교합니다.
조회 오류나 노랑 비율이 크면 해당 지형을 로딩한 뒤 재계산합니다. 계속 실패하면 SDK 높이 지원이나 별도 DEM 자료가 필요할 수 있습니다.
