# 아이폰 문자 → 네이버 메일 → AI 감지 알림

Windows 실행 프로그램에서 네이버 IMAP 받은편지함을 30초마다 읽습니다. 아이폰 단축어가 전달한 메일의 링크를 로그인한 사용자의 **AI 감지 알림**에 표시합니다. 실제 문자 자동전달은 사용자의 새 문자로 별도 확인해야 합니다.

## 감지 영상과 위치 후보

알림 페이지에서 카메라명·감지 영상·표기 시각을 읽고 빨간 테두리를 판독합니다. 저장한 알림 ZIP도 가져올 수 있습니다. 감지 당시 방향이 제공되지 않은 알림은 자동 위치 계산을 보류하며, 당시 장비 값을 확인해 입력한 경우에만 지형 위치 후보를 계산합니다. [사용 방법과 제한](alert-location.md).

## 기존 PC에 적용

1. 중앙 지도 설정을 저장하고 실행 프로그램을 종료합니다.
2. 이번 Windows 업데이트의 **내용 전체**를 기존 실행 폴더에 덮어씁니다. 새 메일 라이브러리와 의존성 파일도 필요하므로 DLL 하나만 복사하지 마세요. 기존 **data 폴더는 유지**합니다.
3. 새로 추가된 **메일수신설정.cmd**를 실행합니다. 기존 서버설정.cmd를 다시 실행하거나 카메라 9대를 다시 입력할 필요가 없습니다.
4. 아래 정보를 이 PC의 설정창에 입력합니다. 비밀번호나 원본 알림 링크를 채팅·GitHub 소스에 올리지 마세요.

| 질문 | 입력 |
| --- | --- |
| 메일 수신 사용 | `y` |
| 네이버 아이디 | `@naver.com`을 제외한 아이디 |
| 네이버 애플리케이션 비밀번호 | 네이버 2단계 인증에서 발급한 앱 비밀번호. 입력은 표시되지 않습니다. |
| 아이폰 Mail에서 보내는 메일 주소 | 단축어의 보내는 계정 주소 전체 |
| FIREWATCHER 문자 링크 또는 알림 서버 주소 | 실제 알림 링크 하나를 붙여넣습니다. 서버의 프로토콜·호스트·포트만 저장하고 링크의 나머지 부분은 저장하지 않습니다. 입력은 표시되지 않습니다. |
| 최초 조회 기간 | 기본 최근 7일. 1~30일 선택. 기존 설정은 `keep`으로 시작일 유지. |

설정 도구는 `imap.naver.com:993`에 인증서 검증을 사용하는 TLS로 접속하고 받은편지함을 읽기 전용으로 열어 확인합니다. 메일을 보내거나 삭제하거나 읽음으로 변경하지 않습니다. 성공한 경우에만 새 설정을 저장합니다.

5. 프로그램을 다시 실행하고 로그인한 뒤 **AI 감지 알림**을 선택합니다.
6. **네이버 메일 연결 정상**이면 프로그램의 메일 조회 연결은 완료입니다. 알림이 0건인 것은 문자 자동전달이 아직 실행되지 않았을 수 있으며, 자동전달 성공을 뜻하지 않습니다.

## 실제 알림을 기다리지 않고 나중에 테스트하기

원할 때 아이폰 기본 Mail에서 **설정한 발신 계정 → 설정한 네이버 받은편지함**으로 메일을 한 통 보냅니다.

- 제목: `[FIREWATCHER]`
- 본문: 기존에 받은 실제 FIREWATCHER 문자 링크 하나. 원본 페이지에서 **알림 해제**를 누르지 마세요.

약 30~60초 뒤 알림 목록에 한 건이 나오는지 확인합니다. 같은 링크를 다시 보내도 보관 중인 동일 알림은 추가되지 않습니다. 이 테스트는 메일 수신 경로만 확인하며 아이폰 문자 트리거의 무인 실행을 증명하지 않습니다.

## 어떤 메일을 읽는가

- 받은편지함(INBOX)만 조회합니다. 자동분류로 다른 폴더에 이동시키지 마세요.
- 설정한 발신 메일 주소가 일치하고 제목이 `[FIREWATCHER]`로 시작하는 메일만 대상으로 합니다.
- 설정한 알림 서버와 프로토콜·호스트·포트가 같고 `/sms/두개의_경로값` 형태인 링크만 받습니다. 관리 페이지·알림 해제 경로·다른 서버의 링크는 받지 않습니다.
- 본문이 있는 메일은 본문에서, HTML만 있는 메일은 HTML에 포함된 링크에서 추출합니다. 첨부파일의 링크는 읽지 않습니다. 전체 문자·메일 본문은 저장하지 않습니다.
- 크기가 512KB보다 큰 메일과 본문이 100,000자를 넘는 메일은 건너뜁니다. 한 번에 최대 50개 메일을 처리하고 다음 조회에서 이어갑니다.
- 조회 시작일 이후 메일 중 처리한 UID와 UIDVALIDITY를 보관합니다. PC 재시작 후 이어서 읽고, 메일함 UID가 바뀌면 시작일 이후를 다시 확인합니다.
- 링크 기준으로 중복을 제거하고 최근 최대 1,000건을 보관합니다. 목록에는 최근 100건을 표시합니다. 보관 한도를 벗어난 오래된 링크는 나중에 다시 전달되면 새 알림이 될 수 있습니다.

## 지도에 표시하기

문자 본문에는 카메라명이 없으므로 링크의 알림 페이지에서 카메라명을 읽습니다. 지도 카메라 연결은 관리자가 확인합니다. 이름이나 카메라 설치 좌표만으로 실제 연기 위치를 추정하지 않습니다.

1. 알림 목록에서 **카메라 확인 필요**인 항목을 선택합니다.
2. **원본 알림 페이지 열기**에서 실제 카메라명을 확인합니다.
3. 관리자로 **연결할 지도 카메라**를 선택하고 같은 카메라 확인 체크 후 **알림 카메라 연결 저장**을 누릅니다.
4. 일반 사용자도 저장된 연결과 **지도에서 알림 카메라 보기**를 사용할 수 있습니다. 일반 사용자는 연결을 변경할 수 없습니다.

연결은 이 알림 한 건에 적용됩니다. 지도 핀은 **카메라 설치점**이며 연기 발생 좌표가 아닙니다. 카메라 설치 좌표를 변경하면 기존 연결은 다시 확인할 때까지 지도에서 숨깁니다. 현재 장비 PTZ를 과거 감지 시점의 방향으로 사용하지 않습니다.

원본 JSON 시각과 화면 표기 시각을 읽되 시간대는 확인 전으로 표시합니다. 메일 작성·메일 도착·프로그램 최초 수신 시각은 각각 구분합니다. 페이지 데이터와 감지 JPG만 수집하고 FIREWATCHER의 알림 해제·삭제 요청 및 페이지 스크립트는 실행하지 않습니다.

## 저장·다른 PC 사용

- `data/firewatcher-mail-settings.protected`: 앱 비밀번호와 메일 필터. Windows 현재 사용자 DPAPI로 암호화합니다.
- `data/firewatcher-mail-state.protected`: 알림 링크·처리 위치·카메라 연결. 같은 방식으로 암호화합니다.
- 다른 Windows 계정/PC에서는 복호화할 수 없습니다. 새 PC는 메일수신설정.cmd에서 한 번 등록해야 합니다. 기존 서버의 웹 화면에 접속하는 다른 PC는 별도 메일 설정이 필요하지 않습니다.
- 이번 메일 설정은 **GitHub시크릿등록.cmd 및 GitHub 서버 배포에 포함하지 않습니다**. 카메라/지도 시크릿 등록은 기존대로 동작합니다. Linux/Docker에서는 이번 Windows 메일 수신을 실행하지 않습니다.
- PC가 꺼진 동안 **메일함에 이미 도착한** 메일은 다음 실행 때 조회합니다. 아이폰 전원이 꺼지거나 단축어 발송이 실패한 문자가 자동 재전달된다고 보장하지 않습니다.
- 메일 보관과 원본 링크 유효기간은 별개입니다. 오래된 원본 페이지가 만료될 수 있습니다.
