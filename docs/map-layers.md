# 공원경계·탐방로와 카메라 위치 불러오기

지도 상단 **지도 레이어 → 지도자료 JSON 불러오기**에서 준비한 지도자료 파일을 선택합니다.
한 파일로 카메라 설치 위치와 공원경계·탐방로를 함께 표시합니다. 초기 시험 위치는 파일의 위치로 대체합니다.
**공원경계**는 초록색, **탐방로**는 노란색 선이며 각각 표시를 켜고 끌 수 있습니다.
**전체 위치·경계 보기**는 현재 표시 자료가 화면에 들어오도록 브라우저 지도를 이동합니다.
카메라 선택과 가상 시점 조정은 레이어를 제거하지 않습니다. CCTV 제어 요청은 없습니다.

## 자료와 보관

사용자가 제공한 두 GPKG는 **EPSG:5181(KGD2002 / Central Belt)**입니다.
GDAL로 **EPSG:4326**으로 변환하며 GeoJSON 좌표 순서는 **경도, 위도**입니다.
경계는 MultiPolygon 1개, 탐방로는 MultiLineString 102개입니다. 다중 도형과 내부 링을 유지합니다.
공원 자료 전체를 표시하며, 카메라 분류와 달리 지리 도형에서 북한산도봉 구간을 임의로 제거하지 않습니다.
`240404` 파일명에 근거한 자료 날짜는 `2024-04-04`로 기록합니다. 최신 탐방로 운영/개방 여부를 보장하지 않습니다.
원본 Z 값은 지면 높이로 검증되지 않았으므로 제거하고 지도 표면에 선을 붙여 표시합니다.

2026-10-12 사용자가 **파일을 브라우저에서 불러오기**를 선택했습니다. 실제 설치 좌표와 원본 GPKG,
변환 자료는 공개 저장소·Pages 기본 자료·공개 Windows 패키지에 넣지 않습니다.
제공한 지도자료는 카메라 이름·설치 위도/경도 9개와 경계·탐방로 도형/표시 이름만 포함합니다.
SSM UUID는 null이며 IP/포트/계정/원본 경로는 포함하지 않습니다. 카메라 방향은 미확인입니다.

파일은 브라우저 메모리에서 읽으며 서버로 업로드하거나 브라우저 저장소에 자동 저장하지 않습니다.
새로고침하거나 다른 PC에서 열면 같은 파일을 다시 선택합니다.
가상 시점 추정값을 편집했다면 **지도자료 전체 다운로드**로 카메라 설정과 레이어를 함께 보관합니다.
기존 **좌표 설정 다운로드 / 중앙 지도 설정 저장**은 카메라 위치·보정값만 포함합니다.

## 표시 방식과 검증 범위

VWorld SDK의 Cesium GeoJSON DataSource에 `clampToGround: true`를 적용합니다.
공원경계는 각 폴리곤의 외부/내부 링을 개별 선으로 그리며 분리된 구간을 연결하지 않습니다.
지원되는 뷰어에서는 GroundPolyline의 ClassificationType.BOTH로 지도 지형과 3D 타일에 붙입니다.
레이어 표시는 카메라 마커/부채꼴과 독립적으로 관리합니다.
레이어 재선택 시 이전 비동기 로딩 결과를 버리며, 표시 실패는 지도 연결 실패와 구분합니다.
SDK 미연결 상태에서도 경계·탐방로와 카메라를 좌표 배치도에서 볼 수 있습니다.

변환 좌표와 도형 수, 실제 입력 파일의 파싱, 브라우저 선택/내보내기와 SDK 메시지 흐름을 검증했습니다.
브라우저 자동 검사는 모의 SDK를 사용합니다. **표시 준비 완료**는 레이어 로딩 완료를 의미하며
실제 VWorld 지형 정합이나 카메라 방향의 정확도 검증을 의미하지 않습니다.
배포 후 실제 지도에서 선이 보이는지 확인하고, 회사 PC에서 영상과 지형을 맞추는 작업을 이어갑니다.

## 로컬 변환 재현 (개발자)

GDAL의 `ogr2ogr`가 필요합니다. 준비된 JSON을 사용하는 PC에는 GDAL을 설치하지 않습니다.

```bash
python3 scripts/prepare-map-data.py \
  --boundary /local/북한산_공원경계_240404.gpkg \
  --trails /local/북한산_탐방로_240404.gpkg \
  --positions config/imports/bukhansan-map-positions.private.json \
  --source-date 2024-04-04 \
  --output config/imports/북한산-지도자료.private.json
```

원본은 읽기 전용으로 열며 기존 출력 파일을 덮어쓰지 않습니다. CRS를 추측하지 않고 EPSG:5181만 변환합니다.
다른 좌표계 자료는 근거를 확인한 뒤 별도 변환합니다. 브라우저는 최대 8MB, 레이어 10개,
도형 10,000개, 좌표점 200,000개와 WGS84 범위/링 닫힘을 검증하고 잘못된 파일은 현재 설정을 바꾸지 않습니다.
GeoJSON의 이름 외 속성과 스타일/주소는 불러오지 않습니다.
