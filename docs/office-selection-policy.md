# 사무소별 Camera Inventory 선택 기준

사용자가 지정한 현재 운용 대상은 이름에 `북한산`이 포함된 카메라이며,
`북한산도봉`이 포함된 카메라는 다른 운용 범위이므로 제외합니다.
2026-10-10 현장 조회 146개에서 이 규칙에 해당하는 카메라는 9개,
북한산도봉 제외 대상은 5개입니다. 실제 이름/UUID와 선택 미리보기는 공개하지 않습니다.

선택된 9개 모두 PtzCap가 존재하고 0이 아닙니다. GET_POS_NORMALIZE 비트는 3개에서 관측됐습니다.
비트 관측은 실제 현재 PTZ 수신 성공을 뜻하지 않습니다. 다른 6개의 직접 SUNAPI/ONVIF 상태 조회
가능 여부도 이 결과만으로 판단하지 않습니다.

향후 다른 사무소로 확장할 때 사무소 분류는 별도 메타데이터로 관리하고 카메라 UUID에 연결합니다.
이름 필터는 최초 분류 제안에 활용하되 운용자가 확인한 사무소 소속을 저장합니다.
이름 변경 후에도 UUID 기반 선택을 유지하고 미분류 카메라를 임의의 사무소에 자동 포함하지 않습니다.
특정 사무소 이름이나 카메라 개수를 코드에 고정하지 않습니다.
이 문서는 운용 요구사항이며 사무소 분류 UI/영구 설정이 이미 구현됐다는 뜻은 아닙니다.

목록·선택 준비에 필요한 이름/UUID/PtzCap는 현재 계정에서 조회됐습니다.
사무소별 전체 등록 범위 대조, 실제 선택 저장·재시작 검증, 설치 좌표,
읽기 전용 현재 PTZ 및 북쪽 방위각/설치 보정/Zoom-FOV는 별도로 확인해야 합니다.
