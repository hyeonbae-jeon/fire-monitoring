# 산불감시 통합 설치·관리

한 PC를 수신기로 사용하고 다른 PC는 같은 HTTPS 웹주소로 접속합니다. 카메라·메일 인증정보와 지도 보정값은 수신기에 보관합니다. 다른 PC마다 프로그램 설치나 초기 설정을 반복하지 않습니다.

## 기존 PC에서 설치·업데이트

1. `Fire-Monitor-Setup` 다운로드를 압축 해제하고 `Setup.cmd`를 실행합니다. 설치와 업데이트에 같은 파일을 사용합니다. Git·GitHub CLI·.NET·Docker 설치가 필요하지 않습니다.
2. 첫 설치에서 **현재 사용 중인 WisenetPtzBridge.exe가 있는 폴더**를 입력하면 그 폴더의 `data`를 가져옵니다. 같은 PC·같은 Windows 계정이어야 기존 암호화 설정을 읽을 수 있습니다. 원래 폴더는 남습니다. 이전 실행 프로그램과 해당 폴더를 실행하는 기존 `FireMonitoringServer` 작업은 중지합니다. 새 도구에서 자동 시작을 다시 등록하세요.
3. 기본 설치 위치는 `%LOCALAPPDATA%\FireMonitoring`입니다. 이후 같은 설치 도구를 실행하면 `app`만 교체하고 `data`는 유지합니다. 다른 폴더의 data를 기존 설정에 합치지 않습니다.
4. 바탕화면 **산불감시**를 실행합니다. `1`은 감시 화면, `2`는 웹 관리자 설정, `3`은 로그인 시 자동 시작, `4`는 자동 시작 해제, `5`는 수신 중지, `6`은 암호화 백업 복원입니다.
5. 새 설치는 최초 관리자 이름과 12자 이상 비밀번호만 등록합니다. 이후 웹에 로그인하여 **관리자 설정**에서 카메라·메일·일반 사용자·지도 키를 입력합니다. 초기 상태에는 카메라 접속 정보가 없습니다. 승인된 9대의 지도 보정값만 포함됩니다.

백그라운드 수신기를 시작한 뒤 도구 창과 브라우저를 닫아도 계속 수신합니다. 수신기를 중지하거나 Windows에서 로그아웃·절전·종료하면 웹접속과 수신도 중단됩니다. 자동 시작은 현재 Windows 사용자의 시작프로그램에 등록되며 **로그인 이후** 실행됩니다. Windows 서비스나 부팅 전 실행 기능은 아닙니다. 재부팅 후 로그인 없이 상시 운영하려면 별도 서비스 배포가 필요합니다. 다른 Windows 계정의 자동 로그인이나 암호 없는 계정을 만들지 마세요.

## 웹에서 공통 설정 수정

관리자로 로그인한 뒤 상단 **관리자 설정**을 누릅니다. 관리자가 아닌 계정에는 이 메뉴가 표시되지 않고 API 접근도 거부됩니다.

- 카메라별 수신 사용·영상 방식·주소·계정·표시 거리를 입력합니다. 한화 장비는 DDNS가 이동한 **최종 장비 주소**를 사용합니다. NVT는 확인한 GetImage 전체 주소를 사용합니다.
- 비밀번호·주소·지도 키의 빈칸은 저장한 값을 유지합니다. 기존 비밀번호나 인증값이 포함된 NVT 주소는 브라우저에 돌려주지 않습니다. 영상 방식 변경 시 새 방식에 맞는 주소를 입력하세요.
- **공통 설정 저장** 시 Windows 사용자 암호화로 저장하고 수신기가 새 설정을 읽습니다. 카메라는 수 초 후 다시 연결하며 메일은 진행 중 조회가 끝난 뒤 다음 조회에서 변경됩니다. 저장 성공과 실제 장비·메일 접속 성공은 별개입니다. 자동 감시·AI 감지 알림에서 실제 수신 상태를 확인하세요.
- 지도 방향은 **자동 감시 → 감시 방향 보정 (관리자) → 근사 기준을 지도 설정에 반영 → 중앙 지도 설정 저장**에서 수정합니다. 같은 수신기를 사용하는 다른 PC는 지도 설정을 다시 불러오거나 새로고침하면 반영됩니다. 여러 수신 PC가 독립적으로 실행 중이면 자동으로 합쳐지지 않습니다.
- 계정 변경 시 기존 로그인은 만료됩니다. 변경한 계정으로 다시 로그인하세요. 일반 사용자는 자동 감시와 AI 감지 알림을 조회합니다.
- 지도 키 변경 후 페이지를 새로고침합니다. 지도 키에는 실제 접속할 도메인 사용 등록이 필요합니다.
- 네이버 메일은 IMAP·앱 비밀번호와 아이폰 자동 전달을 별도로 설정해야 합니다. 실물 아이폰의 새 문자·잠금 상태 전달은 실제 알림으로 확인해야 합니다.

## 다른 PC에서 접속

수신 PC의 `http://127.0.0.1:5080`은 그 PC에서만 열립니다. 다른 PC에는 동일한 수신기로 연결되는 **VPN 또는 HTTPS 주소**를 제공해야 합니다. GitHub Pages는 수신기 주소가 아닙니다. 이 패키지가 실제 외부 주소·VPN·인증서를 자동으로 발급하거나 회사 네트워크 정책을 바꾸지는 않습니다.

예를 들어 조직에서 허용한 Tailscale을 수신 PC와 이용 PC에 설치·로그인한 뒤, 수신 PC에서 다음을 실행하면 VPN 안에서 HTTPS로 접근할 수 있습니다.

```powershell
tailscale serve --bg http://127.0.0.1:5080
```

명령이 출력한 HTTPS 주소를 다른 PC에서 엽니다. Tailscale 네트워크 접근 권한과 모니터링 로그인 모두 필요합니다. 실제 사용 여부는 조직 정책에 맞추세요. 일반 HTTP 포트를 인터넷에 직접 개방하거나 카메라 암호를 URL로 배포하지 않습니다. 기존 회사 VPN과 HTTPS 프록시를 사용해도 됩니다. 승인된 장비에 접근 가능한 네트워크에 수신기가 있어야 합니다.

## 수신 PC 교체와 복구

1. 기존 수신기의 웹 **관리자 설정 → 수신 PC 교체·암호화 백업**에서 16자 이상 백업 암호를 두 번 입력하여 `.backup` 파일을 내려받습니다. 백업 암호는 별도로 안전하게 보관합니다.
2. 새 PC에 통합 설치 도구를 실행합니다. 기존 PC 폴더는 입력하지 않아도 됩니다. 통합 실행 도구의 `6`을 선택하여 백업 파일과 암호를 로컬에서 입력합니다. 최초 관리자 계정을 따로 만들지 않아도 복원이 가능합니다.
3. 백업 당시의 관리자·일반 사용자 계정으로 로그인합니다. 새 PC에서는 해당 Windows 사용자로 다시 암호화합니다. 새 수신기가 정상인지 확인한 뒤 기존 수신기를 중지하고 접속 주소를 전환하세요.

백업에는 카메라 접속 정보·계정 해시·메일 설정·지도 키·현재 지도 보정값이 포함됩니다. 감지 알림 이력과 이미지는 제외됩니다. 원본 HTML·SMS·카메라 영상도 포함하지 않습니다. 백업은 설정을 내보낸 시점의 복구본이며 실시간 동기화 저장소가 아닙니다. 백업 파일과 암호를 함께 공유하거나 공개 GitHub에 올리지 마세요.

같은 PC·같은 Windows 계정의 이전 data는 설치 도구로 가져올 수 있지만, 다른 PC로 `.protected` 파일만 복사하면 해독되지 않습니다. 다른 PC에는 위 암호화 백업을 사용합니다.

## GitHub Secrets의 역할

Secrets는 승인된 배포 작업에 초기 설정을 전달하는 용도로 유지합니다. 실행 프로그램이 Secrets의 저장된 값을 다시 읽어오는 기능은 GitHub에서 제공하지 않습니다. 웹 설정 수정이 GitHub Secrets를 자동으로 바꾸지도 않습니다. 공개 빌드·배포 ZIP에는 운영 비밀번호를 포함하지 않습니다. 공통 설정의 기준은 **운영 중인 수신기**입니다. 이전 배포 Secrets로 수신기 설정을 다시 덮어쓰지 않도록 주의하세요.

회사 PC를 계속 켜둘 수 없다면 Windows 서버/VPS 같은 별도 상시 호스트가 필요합니다. 여러 PC가 수신기 없이 동일한 실시간 상태를 유지할 수는 없습니다. 현재 통합 설정·네이버 메일 수신은 Windows용이며 Linux 컨테이너의 메일 수신은 지원하지 않습니다.
