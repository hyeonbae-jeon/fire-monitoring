# 영상·지형 수동 보정 사용방법

2026-10-10 사용자는 추가 PTZ 인증 조사보다 주변 지형으로 방향을 맞추는 작업을 먼저 진행하기로 했습니다.
첫 대상은 백운대이며 제공 좌표가 실제 설치 위치임을 확인했습니다. 실제 좌표·UUID는 공개 저장소/패키지에 넣지 않습니다.
현재 구현은 **설치 위치에서 가상 지도 시점을 영상에 수동으로 맞추고 추정 설정을 저장하는 시안**입니다.
자동 능선 매칭, 방향 측정 정확도 검증, 실시간 영상/PTZ 수신은 아직 구현하지 않았습니다.

## 한 대에서 시작하기

1. Windows 실행 패키지를 열고 **지도 모니터링**을 선택합니다.
2. **설치 위치 추가**에 확인된 이름·위도·경도를 입력합니다. SSM UUID는 확인된 경우에만 입력합니다.
   기존 private 좌표 JSON을 불러와도 됩니다. 최초 실제 위치 추가는 초기 합성 시험 좌표를 대체합니다.
3. 이 앱의 실제 접속 주소에 허용된 VWorld 3D 키로 연결합니다. 초기화 안내 후 지형이 실제로 보이는지 확인합니다.
4. 해당 카메라의 **단독 주간 원본 화면**을 선택합니다. 모니터를 비스듬히 촬영한 사진보다 직접 저장한 원본이 적합합니다.
   방향·줌을 바꾸지 않고 기존 영상에서 확보한 화면을 사용합니다. 최대 10MB PNG/JPEG/WebP, 3,600만 픽셀입니다.
5. 화면에서 식별한 봉우리·능선·건물 등을 두 곳 이상 클릭하고 이름과 촬영 시각을 기록합니다.
   클릭점은 작업 근거를 남기는 기능이며 지리 좌표 대응이나 자동 각도 계산은 하지 않습니다.
6. 가상 방위각·기울기·수평 화각·설치 높이를 조절하고 **가상 시점 적용**을 누릅니다.
   영상과 지도 비율을 같게 맞추고 지도 마우스 이동을 잠급니다. 반복 적용하며 같은 기준점 배치를 대조합니다.
7. **추정 방향을 설정에 반영** 후 저장 키로 **중앙 지도 설정 저장**하거나 JSON을 다운로드합니다.
   로컬 Windows 패키지 키는 `local-demo-only`입니다. 참조 이미지 원본은 회사의 별도 위치에 보관하세요.

북=0°, 동=90°이며 기울기 양수는 위, 음수는 아래입니다. 초기 각도/높이는 가상 시험값입니다.
화각은 광학 Zoom 값과 다릅니다. 현재는 roll=0인 직선 투영을 사용하며 렌즈 왜곡·크롭·흔들림을 보정하지 않습니다.
틀린 설치 높이·위치·지형 모델이나 비슷한 능선으로도 시각적으로 비슷한 화면이 나올 수 있습니다.
추정값을 확정하려면 보정에 쓰지 않은 기준점과 같은 시점의 추가 원본 화면으로 오차를 별도로 확인해야 합니다.
두 점을 기록했다는 사실만으로 정확도가 보장되지 않습니다. 오차 수치는 아직 산출하지 않습니다.

## 높이와 방향의 상태

지면 높이를 비우면 로드된 지도 표면의 clampToHeight, 이후 사용 가능한 terrain 높이를 읽습니다.
읽지 못한 높이를 0으로 보완하지 않습니다. 지형이 로드될 때까지 기다리거나 지도와 같은 높이 기준의 값을 입력합니다.
건물/수목 표면, 지도 고도 기준과 측량 해발고도의 차이를 확인해야 합니다. 참고 높이는 실측 고도가 아닙니다.
수동으로 입력한 0m는 알려진 입력으로 취급하지만 미입력은 UNKNOWN입니다.

저장 방향은 `source=manual-calibration`, `status=estimate`, `confidence=unvalidated`입니다.
촬영 시각에 해당하는 추정이며 현재 카메라 방향을 수신했다는 의미가 아닙니다.
화면 방향·줌이 달라지면 **화면 방향·줌 변경으로 보정 무효화**를 누르고 다시 맞춥니다.
무효화한 값은 이력에 남지만 `stale`/방향 UNKNOWN으로 표시하고 추정 부채꼴을 숨깁니다.
현재 자동 변화 감지나 자동 만료는 없습니다. 주황색 부채꼴의 거리는 임의 표시값이고 지형 차폐/실제 촬영 범위는 계산하지 않습니다.

## 중앙 저장과 개인정보

Bridge 환경변수 `MAP_CONFIG_FILE`에 Inventory/선택 파일과 다른 경로를 지정합니다.
`GET /api/map-configuration`은 SHA256 revision과 설정을 반환합니다. 없는 파일은 `revision=none`입니다.
`PUT /api/map-configuration`은 `X-Inventory-Write-Key`와 `{configurationRevision, configuration}`을 요구합니다.
다른 브라우저가 수정하면 409로 충돌을 알립니다. 잘못된 기존 파일은 덮어쓰지 않습니다.
`orientation=null`인 기존 schemaVersion=1 EPSG:4326 파일도 불러올 수 있습니다.
실제 좌표·UUID·참조 시각/이미지 해시·기준점 정보는 운영 자료이므로 공개 저장소로 올리지 않습니다.

참조 이미지는 이 앱이 업로드하지 않고 현재 브라우저 메모리/Blob URL로 표시합니다.
서버에는 해시·해상도·촬영 시각·기준점 메타데이터와 추정 시점만 저장합니다. 재실행 시 원본 이미지 선택이 필요합니다.
지도 키·원본 파일 이름·영상 데이터는 설정에 포함하지 않습니다. 이미지 해시 생성에는 HTTPS 또는 localhost가 필요합니다.
키는 VWorld SDK 요청에 전달되므로 브라우저에서 확인 가능한 값이며 등록 접속 범위로 관리합니다.

Windows 패키지는 루프백에 실행되고 `data/map.demo.json`을 사용합니다. 다른 PC 접근용 서버 배포는 아직 수행하지 않았습니다.
중앙 Bridge에 웹앱을 함께 배포하면 같은 주소의 브라우저들이 지도 설정을 공유합니다.
운영 중앙 배포는 HTTPS·조회/쓰기 인증 프록시와 운영자가 정한 저장 키를 사용해야 합니다.
이 기능은 SSM/카메라 접속 또는 CCTV 명령을 보내지 않습니다.

## 검증 범위와 다음 자료

HTTP 저장·충돌·손상 파일 보존, 모의 SDK의 각도/화각/높이·이미지 제외·재시작·무효화 흐름을 테스트합니다.
모의 SDK 테스트는 실제 VWorld 인증/지형 로딩이나 카메라 방향 정확도의 증거가 아닙니다.
백운대 단독 주간 원본 화면과 촬영 시각을 받은 뒤 실제 지형에서 한 대의 정합을 확인하고 다른 카메라로 확장합니다.
