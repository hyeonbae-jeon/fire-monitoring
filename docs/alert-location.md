# 감지 박스를 지도 위치 후보로 확인하기

## 이번에 연결한 기능

FIREWATCHER 알림의 `const eventInfo = {...}` JSON과 감지 JPG를 읽습니다. 사용자 제공 저장 페이지에서 확인한 필드는 `cctv_info`, `cctvName`, `eventName`, `evtTime`, `mapping_Info`, `shortId`입니다. 페이지 스크립트는 실행하지 않습니다.

사용자가 제공한 알림에는 감지 당시 Pan·Tilt·Zoom이 없고 `mapping_Info`도 빈 배열이었습니다. 따라서 **이 과거 알림의 감지 위치를 자동으로 복원한 것은 아닙니다.** 카메라 설치 좌표와 영상 속 대상의 좌표는 구분합니다. 제공자 좌표로 저장한 지도 설치점을 덮어쓰지 않습니다.

## 화면에서 사용하기

1. 프로그램을 업데이트하고 관리자로 **AI 감지 알림**을 엽니다. 카메라·메일 설정은 유지합니다.
2. 메일로 받은 알림을 선택하면 원본 페이지의 카메라명·감지 종류·표기 시각과 감지 영상을 읽습니다. 기존 알림은 **알림 페이지 다시 읽기**를 사용할 수 있습니다.
3. 새 문자를 기다리지 않고 확인하려면 **저장한 알림 페이지 ZIP 불러오기**에서 HTML과 함께 저장한 폴더가 들어 있는 ZIP을 선택합니다. ZIP 안의 HTML은 한 개여야 합니다. 이것은 문자 자동전달 성공 검증과 별개입니다.
4. **연결할 지도 카메라**를 선택하고 원본과 같은 카메라인지 확인한 뒤 **알림 카메라 연결 저장**을 누릅니다. 이름을 읽었다는 이유만으로 자동 연결하지 않습니다.
5. 영상의 빨간 테두리를 자동 판독합니다. 후보가 여러 개면 **감지 박스 N 선택**을 누릅니다. 놓친 박스는 영상 위에서 드래그해 지정할 수 있습니다. 노란 테두리가 선택 영역입니다.
6. **감지 위치 후보 계산**을 펼칩니다. **감지 당시** Pan·Tilt·Zoom을 입력하고 전체 촬영 영역 및 당시 값임을 확인합니다. 모르면 계산을 보류합니다. 현재 장비 값이나 저장한 기준 장비 값을 과거 알림에 자동 대입하지 않습니다.
7. **지형 위치 후보 계산**을 누르면 기존 카메라 보정값으로 방향을 구하고 VWorld 지형을 조회합니다. 박스 하단 왼쪽·중앙·오른쪽의 시선과 지형 교차점을 주황색으로 표시합니다. 중앙 시선의 교차점이 있으면 좌표와 시선 거리를 표시합니다.

**당시 방향을 모르는 과거 영상에서는 원본 영상·박스 확인까지만 가능합니다.** 자동 위치 표시를 완성하려면 제공자에서 감지 당시 장비 방향을 제공하거나, 해당 시각에 대응하는 검증된 방향 기록/영상 대응이 필요합니다. 이번 버전은 과거 PTZ 이력을 새로 만들어내거나 현재값을 과거값이라고 저장하지 않습니다.

## 위치 후보의 의미

- 좌표는 선택한 박스 하단 시선을 지형에 투영한 **배경 지형 위치 후보**입니다. 실제 연기·불꽃의 발생 좌표로 확정하지 않습니다.
- 공중에 떠 있는 연기나 불빛은 배경 지형과 거리가 다를 수 있습니다. 박스 하단도 발화점이라는 보장은 없습니다.
- 저장한 근사 보정값과 줌 화각 모델을 사용합니다. 렌즈 왜곡·기울어진 설치·모델 오차·지도 지형 오차를 포함한 정확도는 검증하지 않았습니다.
- 25m 간격으로 시선을 따라 지형을 읽고 첫 번째 교차 구간을 보간합니다. **25m는 표본 간격이며 위치 오차나 신뢰 반경이 아닙니다.** 얇은 능선 등 표본 사이의 지형을 놓칠 수 있습니다.
- 앞쪽 지형 표본이 없으면 뒤쪽 지형을 대상으로 대신 표시하지 않습니다. 평면/타원체 높이를 실제 지형 대신 사용하지 않습니다.
- 렌즈가 조회된 지형 아래이거나, 시선이 조회 한도 안에서 지형과 만나지 않으면 좌표를 표시하지 않습니다.
- 조회 한도는 기본 3,000m, 최대 20,000m입니다. 감지 가능 거리 또는 이 거리에서 실제 대상이 있다는 뜻이 아닙니다.
- 박스 선택·PTZ·영상·지도 설치점/보정값이 바뀌면 이전 계산을 무효화합니다. 늦게 도착한 지형 응답은 현재 결과를 덮어쓰지 않습니다.
- 위치 후보는 현재 브라우저 화면에서만 유지합니다. 중앙 지도 보정값이나 다른 사용자의 지도 설정을 수정하지 않습니다. 일반 사용자는 원본 영상·박스를 보고 관리자가 확인한 카메라 설치점으로 이동할 수 있으며 관리용 입력은 표시하지 않습니다.

## 감지 시각

원본 JSON의 `evtTime`과 화면에 표기된 날짜 문자열을 따로 읽습니다. 제공된 페이지에서는 ISO 시각의 `Z`와 화면 날짜의 시간대 의미를 확인할 수 없었습니다. 원본 문자열을 표시하고 **시간대 확인 전**으로 남깁니다. 메일 도착·작성 시각을 감지 시각으로 바꾸지 않습니다. 시각 문자열만으로 현재 PTZ나 임의의 과거 표본을 연결하지 않습니다.

## 저장과 읽기 범위

- 설정한 알림 origin과 `/sms/두개의_경로값`에 한정해 읽습니다. 페이지가 제시하는 같은 서버의 해당 shortId JPG만 읽고 리다이렉트·쿠키·장비 인증을 전달하지 않습니다. `/api/`·알림 해제/켜기 등 관리 경로는 이미지로 읽지 않습니다.
- HTML의 JavaScript, VWorld 초기화 코드, 알림 해제 버튼은 실행하지 않습니다. 원본 시스템의 상태 변경 요청을 보내지 않습니다.
- 원본 HTML·첨부 ZIP은 저장하지 않습니다. 추출한 알림 필드와 수집 상태를 기존 암호화 상태 파일에 추가합니다. 전체 문자 본문·원본 서버의 파일시스템 이미지 경로·지도 SDK 키는 추출 자료에 넣지 않습니다.
- 원본 감지 JPEG는 `data/firewatcher-images`에서 Windows 현재 사용자 DPAPI로 암호화해 최대 100개 보관합니다. 각 JPEG는 최대 2MB입니다. 보관 한도를 벗어나면 원본 페이지 다시 읽기가 필요할 수 있습니다.
- 알림 페이지는 최대 1MB, 가져오는 ZIP은 최대 12MB·150개 파일·전체 압축 해제 크기 32MB입니다. ZIP을 실행 폴더에 압축 해제하거나 스크립트를 실행하지 않습니다.
- 영상은 인증된 서버의 `/api/firewatcher-mail/image`에서 제공하며 일반 사용자도 읽을 수 있습니다. ZIP 가져오기·원본 다시 읽기·카메라 연결 변경은 관리자 및 CSRF 확인이 필요합니다.
- 감지 페이지의 카메라 ID/이름이 바뀌면 기존 카메라 연결을 다시 확인하도록 해제합니다. 원본 알림을 해제하는 동작과 다릅니다.
- 실행 패키지·공개 Pages·소스에는 운영 알림 페이지와 감지 이미지를 포함하지 않습니다. 다른 PC로 암호화 data를 옮겨 복호화할 수는 없습니다.
