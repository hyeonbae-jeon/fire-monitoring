# SSM 화면의 읽기 전용 실시간 수집 시험

사용자는 2026-10-11 SSM 영상이 표시되는 회사 PC에서 시험 도구를 함께 실행할 수 있다고 확인했습니다.
최종 목표는 회전형 카메라의 현재 영상을 계속 받아 지형을 대조하고 촬영 방향을 VWorld에 갱신하는 것입니다.
이번 단계는 **1초마다 선택 영역을 수집하고 브라우저에 표시하는 것**까지입니다.
자동 방향 추적, PTZ 수신, 정확한 회전/줌 판별은 구현하지 않았습니다. 방향은 항상 UNKNOWN입니다.
백운대와 숨은벽의 정지 화면은 해당 촬영 시각의 보정 자료이며 회전 후 현재 방향으로 유지하지 않습니다.

## 회사 PC에서 실행

1. 최신 Windows 패키지 전체를 쓰기 가능한 폴더에 풉니다. Git/.NET/Node 설치는 필요 없습니다.
2. SSM Console Client의 **라이브 보기**에서 백운대 한 대의 영상을 크게 표시합니다. 기존 로그인 상태를 사용합니다.
3. 패키지의 `WisenetPtzBridge.exe`와 `화면캡처.cmd`를 실행합니다.
4. 수집 도구에서 카메라 이름을 입력하고 **영상 영역 선택**을 누릅니다. 영상 부분만 드래그합니다. Esc로 취소할 수 있습니다.
5. 도구 창을 SSM 영상과 겹치지 않는 위치나 다른 모니터로 옮기고 **수집 시작**을 누릅니다.
6. 도구의 미리보기가 실제 SSM 영상과 일치하는지 확인합니다. 일치하면 확인 체크박스를 선택합니다.
7. 브라우저의 **실시간 화면 시험 → 라이브 화면 확인**에서 수집 시각과 최신 화면을 확인합니다.
   **참조 화면 저장**으로 표시 중인 영상 영역의 JPEG를 PC에 내려받을 수 있습니다. 저장 파일은 회사의 별도 장소에 보관하세요.
8. 평소 운용 중 화면이 움직이면 **화면 변화 감지** 표시를 확인합니다. 시험을 위해 카메라 제어 명령을 보내지 않습니다.
9. 도구의 **수집 중지**를 누릅니다. 결과는 `data/capture.private/screen-capture-report.private.json`에 남습니다.

브라우저의 **라이브 표시 중지**는 조회만 중지합니다. 수집 자체는 별도 도구에서 중지합니다.
수집 시각은 PC에서 화면을 읽은 시각이며 카메라의 실제 노출 시각은 미확인입니다.
녹화 재생이나 멈춘 원본 영상도 새 화면으로 캡처될 수 있습니다. 원본 스트림의 현재성은 SSM에서 확인하며 자동 검증하지 않습니다.
카메라 전환·분할 배치 변경·SSM 창 크기 변경 후에는 수집을 중지하고 이름과 영역을 다시 지정하세요.
SSM 설정/로그인 화면을 열기 전에도 수집을 중지하세요. 이름은 사용자가 입력한 표식이며 화면에서 UUID를 식별한 값이 아닙니다.

## 멈춤과 화면 변화의 의미

- 선택한 SSM 프로세스(`ConsoleStudio2`)와 창 내부 영역에 연결됩니다. 다른 앱을 대상으로 선택하지 않습니다.
- SSM 창이 닫히거나 최소화되면 수집을 일시 중지합니다. 창 이동은 상대 좌표를 따라가며 크기 변경은 재선택이 필요합니다.
- 선택 영역 위에 다른 창이 겹치면 수집을 일시 중지하고 이미지를 지웁니다. 가림이 해소되면 재개합니다.
- 브라우저는 새 화면이 4초 이상 들어오지 않으면 이전 이미지를 숨깁니다. 요청이 멈춘 경우에도 만료를 확인합니다.
- 화면 변화는 작은 회색조 표본을 기준 화면과 비교합니다. 느린 변화도 누적 비교하며 두 번 연속 임계값을 넘으면 표시합니다.
- 조명·안개·움직이는 물체도 변화를 일으킬 수 있습니다. 변화 감지는 카메라 회전/줌 측정이나 지도 방위각 계산이 아닙니다.
- 검은/저대비 화면은 안내합니다. 야간 영상인지 캡처 방식의 문제인지는 실제 SSM 화면과 비교해야 합니다.
- **화면 변화 기준 새로 설정**은 비교 기준만 바꿉니다. 지형 방향을 보정하거나 PTZ를 움직이지 않습니다.

캡처는 Windows 화면 픽셀을 읽는 방식입니다. SSM의 GPU/보호 영상·원격 접속·화면 잠금과의 호환성은 현장 시험이 필요합니다.
가림 검사는 보이는 상위 창의 경계를 사용하며 캡처 전후에 확인합니다. SSM 내부에서 카메라를 바꾸거나 메뉴를 여는 것은 자동으로 식별하지 않습니다.

## 저장과 연결 범위

최신 JPEG 두 장과 작은 상태 JSON만 로컬 교환 폴더에 보관합니다. 중지·가림 시 이미지는 지우며 영상 녹화 파일을 만들지 않습니다.
비정상 종료 뒤에는 남은 이미지가 있을 수 있으나 브라우저/API는 만료된 영상을 반환하지 않습니다. 다음 수집 시작에서 정리합니다.
상태/결과에는 입력한 카메라 이름·시각·화면 크기·변화 지표가 포함됩니다. 원본 영상/운영 결과를 공개 GitHub나 패키지에 넣지 않습니다.
기존 SSM 계정·비밀번호·쿠키를 읽거나 네트워크 CCTV 요청/제어 명령을 보내지 않습니다.

로컬 패키지는 루프백에만 바인딩하고 공개 로컬 키를 자동 적용합니다. 다른 PC 접근용 중앙 배포는 아직 하지 않았습니다.
개발/중앙 Bridge에서 쓰려면 `CAPTURE_SOURCE_DIR`에 교환 폴더의 절대 경로와 `CAPTURE_READ_KEY`를 지정합니다.
조회는 `X-Capture-Read-Key` 헤더를 요구합니다. 키는 URL/브라우저 저장소에 넣지 않습니다.
`GET /api/screen-capture/status`, `GET /api/screen-capture/frame?sessionId=…&sequence=…`를 사용합니다.
다른 세션/이전 순서/만료/가림/잘못된 상태의 이미지는 반환하지 않습니다. 중앙 배포 시 HTTPS/접근 통제가 별도로 필요합니다.

## 검증 범위

합성 데이터로 변화 감지·가림 정책·최신 두 장 보관/중지 삭제·인증·만료·세션 일치·JPEG 크기·브라우저 표시/만료를 시험합니다.
Windows x64 도구의 빌드/런타임 포함 패키지를 생성합니다. 실제 Windows SSM 캡처는 회사 PC 시험이 남아 있습니다.
실제 지도 정합과 방위각 정확도, 밤/안개/큰 회전 뒤 재대응은 이 시험의 완료 범위가 아닙니다.
