# 지도 기준점으로 방향·화각 공동 보정

참조 사진의 픽셀 위치와 VWorld 지도상의 같은 지형 좌표를 연결해 가상 방위각·기울기·수평 화각을 함께 계산합니다.
카메라 이동이나 PTZ 조회는 하지 않습니다. 결과는 촬영 시각의 **정확도 미검증 후보**이며 현재 방향의 실시간 수신값이 아닙니다.
두 장의 영상 대응 시험에서 얻은 유효 화각 후보도 장비 측정값으로 취급하지 않습니다.

## 사용 순서

1. 지도에서 실제 설치 위치가 맞는 카메라를 선택하고, 기존 설정 JSON이 있으면 먼저 불러옵니다.
2. 참조 CCTV 이미지와 실제 촬영 시각을 입력합니다. 사진을 바꾸면 기준점을 새로 지정합니다.
3. **참조 영상 크게 보기**에서 식별 가능한 같은 지점을 4개 이상 클릭합니다. 좌우와 높이가 다른 지물에 분산합니다.
   봉우리 이름만 같게 적는 대신 꼭대기·바위 모서리 등 사진과 지도에서 동일하게 식별할 지점을 사용합니다.
4. **지도 기준점으로 방향·화각 함께 계산**의 각 **N번 기준점 지도에서 지정**을 누르고 지도에서 같은 지점을 클릭합니다.
   지정 중에는 지도 이동이 가능합니다. 카메라 마커를 지형 꼭대기로 대신 사용하지 않습니다.
   지도 표면을 읽지 못하는 하늘·미로딩 지점은 거절합니다. 취소하거나 다른 카메라/도구로 전환하면 진행 중인 지정은 무효화합니다.
5. 연결한 점 중 1개 이상을 **검증용 · 계산에서 제외**로 선택합니다. 나머지 계산용은 3개 이상이어야 합니다.
6. 가상 설치 높이를 입력하고 지도 지면 고도는 기본 **지도에서 자동 조회**로 둡니다.
   3m는 새 시점의 시험 기본값이고, 사용자가 선택한 다른 높이도 실측 확인 전까지 시험값입니다.
7. **기준점으로 방향·화각 계산**을 누릅니다. 계산만으로 지도 시점이나 저장 설정은 바꾸지 않습니다.
8. 각 점의 픽셀 오차와 계산점/검증점 RMS를 확인합니다. 허용된 후보에 한해 **계산 후보를 지도에 적용**할 수 있습니다.
   계산 당시의 지도 지면 고도를 재사용해 지도 타일 높이의 재조회 차이로 적용 시점이 바뀌지 않게 합니다.
9. 지도와 참조 영상을 확인한 뒤 **추정 방향을 설정에 반영**하고 JSON 다운로드 또는 로컬 Bridge 저장으로 보관합니다.
   기존 참조의 설정 파일도 별도 이름으로 보관하세요. 현재 설정에는 카메라당 한 시점의 보정 후보만 있습니다.

### 후보가 거절될 때

**보정 진단 다운로드**는 적용하지 못한 현재 기준점·지도 좌표·고도·영상 크기와 해시·계산 후보·가로/세로 잔차를 별도 `calibration-diagnostics.private.json`에 담습니다.
계산 전에 찍어 둔 점도 보관할 수 있습니다. 입력이 바뀌면 이전 계산/고도 결과는 제거합니다.
**좌표 설정 다운로드**는 설정에 반영한 값만 내보내므로 두 파일의 용도가 다릅니다. 진단 파일은 지도 설정으로 불러오지 않습니다.
진단 다운로드는 지도 시점이나 저장 설정을 변경하지 않으며 서버에 자료를 전송하지 않습니다. 이미지 원본·지도 키·장비 연결 정보도 넣지 않습니다.

계산점에도 오차가 크면 검증점만 교체해 통과시키지 말고 지물 대응·설치 좌표와 고도·크롭·수평선 회전·지도 표면을 확인합니다.
지도 카메라 마커는 설치 위치이며 봉우리 꼭대기를 대신하지 않습니다. 원인을 구분할 때 진단 파일과 기준점 번호가 보이는 참조 화면을 함께 확인합니다.
오차 기준을 완화하거나 실패 후보를 현재 방향으로 간주하지 않습니다.

원본 사진은 업로드하거나 JSON에 넣지 않습니다. 지도 좌표·고도와 계산 근거는 운영 자료이므로 공개 기본 자료/소스에 넣지 않습니다.
Pages는 파일 보관용이고 중앙 저장 키가 없습니다. 로컬 Windows Bridge의 저장 키는 시험 패키지의 `local-demo-only`입니다.
공동 계산 근거를 담은 새 JSON을 로컬 프로그램에서 불러올 때는 이 기능이 포함된 최신 실행 패키지를 사용합니다. 이전 형식의 파일은 새 버전에서도 읽습니다.

## 계산 모델과 제한

- WGS84 ECEF에서 카메라 설치점 기준 ENU 방향을 계산합니다. 지면 고도와 렌즈 높이는 고정 입력입니다.
- 직선 투영, 가로·세로 동일 픽셀 초점거리, 영상 중앙 주점, roll=0을 가정합니다.
  크롭·렌즈 왜곡·전자 안정화·수평선 회전·지도 표면 오차와 실제 광학 줌 단위를 해결하지 않습니다.
- 의존성 없는 3변수 최소제곱으로 방위각·기울기·수평 화각을 함께 맞춥니다. 별도 검증점은 계산에서 제외합니다.
- 계산용 점의 영상 범위는 가로 15%, 세로 5% 이상이어야 하며 설치점에서 20m~50km 지물만 사용합니다.
  중복 지도 지점, 누락 고도, 불안정한 조건수와 파라미터 경계의 결과는 거절합니다.
- 시안의 적용 기준은 계산점 RMS ≤5px, 검증점 RMS ≤10px, 최대 오차 ≤15px, 조건수 <1000입니다.
  이는 초기 실험 기준이며 운영 정확도를 보증하지 않습니다. 같은 점들의 잔차가 작아도 실제 위치 정확도와 다릅니다.
- 보정값의 출처/상태는 `manual-calibration / estimate / unvalidated`를 유지합니다.
  `landmarks[].mapPoint`, 선택적인 `useForValidation`, `geographicFit`에 지도 근거와 잔차를 보관합니다.
  기존 2D 기준점 JSON은 그대로 읽습니다. 계산 근거가 있으면 웹앱과 Bridge 모두 시점·기준점으로 잔차를 재계산해 일치 여부를 검사합니다.
- 설치점·이미지·높이·지도 기준점·검증 역할을 바꾸면 계산 결과를 무효화합니다. 각도를 수동 조정하면 공동 계산 근거를 해제합니다.

## 실시간 시험과의 순서

SSM 화면 → 수집 도구 → 회사 PC 로컬 브라우저의 영상 갱신은 사용자가 이미 확인했습니다.
이번 기능은 저장된 기준 사진의 방향·화각 보정입니다. 이후 연속 캡처의 자동 영상 대응·신뢰도·지도 시점 갱신을 통합 검증합니다.
직접 영상 스트림 연결과 SSM 창 최소화 상태의 수신은 별도 인터페이스·권한 확인 항목입니다.
공개 Pages에서 회사 CCTV를 직접 조회하거나 회사 밖 PC로 전달하는 기능은 추가하지 않습니다.

## 검증 범위

별도 OpenCV 투영으로 만든 합성 지도 좌표/픽셀의 정답 복원, 북쪽·영상 축·방위각 순환·세로 영상,
검증점 독립성·잘못된 대응·퇴화 배치·누락 고도 거절을 확인합니다.
브라우저의 지도 지정·취소·과거 응답 거절·명시적 적용·내보내기와 Bridge 저장·재시작·잘못된 근거의 기존 파일 보존을 검사합니다.
운영 CCTV 원본과 현장 좌표는 자동 테스트에 사용하지 않습니다. 실제 VWorld 클릭 고도와 보정 정확도는 회사 PC에서 별도 확인해야 합니다.
