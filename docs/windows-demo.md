# Windows 실행 패키지 사용방법

대상: Windows 10/11 64비트(x64) PC. Git, .NET, Node.js를 설치하지 않아도 됩니다.
ZIP 안에 .NET 런타임과 웹앱이 포함되어 있으며 실행 시 다운로드하지 않습니다.

## 실행

GitHub Actions에서 다운로드할 경우 GitHub에 로그인한 뒤 실행 결과의
`Windows-Camera-Inventory-Demo` 아티팩트를 클릭하세요.
아티팩트 ZIP을 먼저 풀면 실행 패키지 ZIP과 SHA256 파일이 나오며, 실행 패키지 ZIP도 풀어야 합니다.
아티팩트는 30일 동안 보관됩니다. 만료되면 workflow를 다시 실행해 새 파일을 만들 수 있습니다.

1. ZIP 파일을 회사 PC로 가져가 전체 압축을 풉니다. ZIP 안에서 바로 실행하지 마세요.
2. 압축을 푼 폴더의 `WisenetPtzBridge.exe`를 더블클릭합니다.
3. 콘솔 창과 기본 브라우저가 열립니다. 콘솔 창을 닫으면 서버도 종료됩니다.
4. 샘플 카메라를 선택하고 웹 화면의 저장 키에 `local-demo-only`를 입력합니다.
5. '선택한 카메라 저장'을 누르면 같은 폴더의 `data/cameras.demo.json`에 저장됩니다.
6. 종료 후 다시 실행하여 선택이 유지되는지 확인합니다.

저장 키는 공개된 로컬 샘플 전용 값이며 운영 비밀번호가 아닙니다.
브라우저가 열리지 않으면 콘솔의 `Browser:` 옆 주소를 복사하여 주소창에 입력하세요.
포트는 자동으로 선택되므로 실행할 때마다 주소가 바뀔 수 있습니다.
PC 밖에서 접속할 수 없도록 루프백 주소에만 바인딩합니다.

## 이번에 테스트할 수 있는 것

- 샘플 이름/UUID/PTZ capability 조회, UNKNOWN과 없음 구분
- 검색, 여러 카메라 선택, 중앙 설정 저장
- 프로그램을 종료하고 다시 실행했을 때 선택 유지

**Wisenet SSM에 실제로 연결하지 않습니다.** 회사 PC에 Wisenet 프로그램이 있어도 자동으로
카메라를 읽지 않습니다. `demo/inventory.json`은 합성 샘플이며 실제 장비 목록이 아닙니다.
PTZ 제어/구독/영상 조회, VWorld 지도는 포함하지 않습니다. 운영 환경변수나 SSM 비밀번호도
사용하지 않습니다. 운영 cameras.json과 별도의 data/cameras.demo.json만 사용합니다.

실제 전체 SSM 목록 연결은 외부 조회 인터페이스의 인증/UUID/필드/페이지 처리 확인이 선행되어야 합니다.
이번 실행 패키지는 설치 없이 UI와 저장 기능을 시험하기 위한 버전입니다.

## 실행이 안 될 때

- 압축을 모두 풀었는지, exe와 wwwroot 및 나머지 DLL 파일이 같은 폴더에 있는지 확인하세요.
- 브라우저가 열리지 않으면 콘솔의 Browser 주소로 직접 접속하세요.
- 오류 창이 바로 닫히면 `문제진단.cmd`를 실행해 오류를 확인하세요.
- 저장 오류는 압축을 푼 폴더의 쓰기 권한을 확인하세요. 기존 파일을 삭제할 필요는 없습니다.
- 회사 보안 정책이 실행을 차단하면 담당자에게 확인하세요. 이 패키지는 코드 서명되지 않았습니다.

검증 범위: Linux 빌드 환경에서 Windows x64 self-contained publish 및 ZIP 무결성 검증.
공통 웹/Bridge와 로컬 시연 시작·저장 경로는 테스트하며, Windows GUI 실행은 회사 PC에서 확인해야 합니다.
