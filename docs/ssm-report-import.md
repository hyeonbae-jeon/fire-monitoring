# SSM 장치 설정 리포트 반영

## 첨부 파일에서 확인된 사실

첨부 .xls는 바이너리 Excel이 아니라 UTF-8 Excel 2003 SpreadsheetML XML입니다.
Camera 시트 140행과 SSM Server 시트 2행이 있으며 카메라 Name과 Guid는 각각 140개의 고유한 값입니다.
Camera의 PTZ 표시값은 지원함 137개, 지원 안 함 3개입니다.
Status는 CONNECT 134개, DISCONNECT 6개입니다. 이는 내보낸 시점의 보고서 기록이며 실시간 상태가 아닙니다.
SSM Server의 Version 열에 2.21.00이 확인됩니다. 별도 행의 5.34.52는 임의로 같은 SSM 버전으로 해석하지 않습니다.
모델 XNP-6550RH는 13행에 나타납니다. 원하는 선택 대수나 특정 카메라 그룹을 임의로 정하지 않습니다.

Guid 열은 보고서 내 카메라 식별자로 사용합니다. 실제 이벤트/외부 API에서 같은 UUID를 사용하는지는
추후 실제 응답과 대조해야 합니다. UUID를 새로 만들거나 모델/이름으로 추측하지 않습니다.
PTZ 표시값은 bool reportedPtzSupported에 별도로 기록합니다.
PtzCap, GET_POS_NORMALIZE, ABSOLUTE_ZOOM, ENTITY_CAPABILITY, 구독 적격 여부는 UNKNOWN입니다.
CameraType의 NONE을 고정 카메라나 PTZ 미지원으로 해석하지 않습니다.
현재 Pan/Tilt/Zoom, 위치 좌표, 실제 북쪽 기준 방향, FOV는 이 리포트에 없습니다.
전체 시스템/사용자 권한 범위와 정확한 수집 시각도 파일만으로 확정하지 않습니다.

## 프로그램에서 가져오기

1. 새 Windows 패키지를 실행하고 카메라 목록 탭에서 장치 설정 리포트(.xls)를 선택합니다.
2. 브라우저에서 미리보기의 수량, 이름, Guid, 모델, PTZ 표시를 확인합니다.
3. 실제 보고서 수집 시각을 PC의 시간대 기준으로 입력합니다. 파일명의 숫자를 수집 시각으로 자동 확정하지 않습니다.
4. 보고서가 전체 등록 카메라 목록인지 SSM 화면/관리 권한/출력 범위와 대조한 경우에만 확인 체크를 합니다.
5. 설정 저장 키(로컬 패키지: local-demo-only)를 입력하고 리포트를 카메라 목록에 반영합니다.
6. 원하는 카메라를 선택하고 키를 다시 입력한 뒤 선택한 카메라 저장을 누릅니다.

전체 여부가 아직 확인되지 않았으면 미리보기만 사용합니다. 부분 목록을 전체로 표시하지 않습니다.
기존 선택 설정은 목록 가져오기만으로 제거하지 않습니다. 사라진 UUID는 화면에서 알려주며
명시적으로 선택을 해제하기 전에는 저장을 막습니다. 전체 선택 수를 9대로 고정하지 않습니다.
지도 좌표 설정과는 별도이며 이 보고서로 북한산 임의 시험 위치를 실제 카메라에 붙이지 않습니다.

## 정보 처리와 저장

원본 파일은 브라우저에서 파싱합니다. 허용한 Name/Guid/Model/PTZ 열만 정규화 JSON으로 Bridge에 보냅니다.
IP/서버 IP/포트/MAC/시리얼/펌웨어/스토리지/설명/영상 프로파일/서버 시트 등은 전달하지 않습니다.
XML 내 지시나 URL을 실행하지 않으며 DTD/ENTITY를 거부합니다. 10MB를 초과한 파일, 잘못된 UUID,
중복 Guid, 필수 열 누락은 전체 가져오기를 거부합니다. PTZ의 미확인 문구는 null입니다.

POST /api/inventory는 X-Inventory-Write-Key 인증과 기존 inventoryVersion을 검사합니다.
다른 브라우저에서 목록이 바뀌면 409로 거부합니다. 설정된 목록 파일만 원자적으로 교체하며
선택 설정 파일과 같은 경로는 거부합니다. 입력 계약의 complete=true, 수량, 시각, UUID 검증도 유지합니다.
선택 저장과 목록 교체는 프로세스 내 공통 gate로 직렬화합니다. 기존 권고대로 중앙 Bridge 한 곳에서 파일을 관리합니다.
로컬 패키지는 demo/inventory.json에 정규화 목록, data/cameras.demo.json에 선택 설정을 보관합니다.
재시작해도 유지되며 운영 환경변수로 지정된 파일에는 쓰지 않습니다.

실제 첨부 리포트의 정규화 미리보기는 로컬 config/imports/report-preview.json에 보관하고 Git에서 제외합니다.
수집 시각과 전체 여부가 미확인이므로 capturedAt=null, complete=false 상태이며 그대로 운영 입력으로 쓰지 않습니다.
원본과 실카메라 이름/Guid/주소는 GitHub와 배포 ZIP에 포함하지 않습니다. ZIP은 합성 샘플로 시작합니다.
프로그램에서 가져온 뒤에는 해당 폴더에 실제 이름/식별자가 저장되므로 그 폴더는 업무 자료로 관리합니다.

CCTV/SSM에 조회나 제어 명령을 보내지 않습니다. 이 리포트는 인증/페이지 처리/실시간 PTZ API 계약의 확인을 대체하지 않습니다.
