# 로컬 영상 대응과 지도 시점 갱신 시험

회사 PC에서 이미 수집되는 화면을 고정된 참조 사진과 비교합니다. 직접 스트림·PTZ 조회/제어·외부 영상 전송은 추가하지 않습니다.
이 기능은 **로컬 Windows 실행 패키지의 지도 모니터링 → 실시간 영상**에 있습니다. 공개 Pages에서는 회사 영상과 연결하지 않습니다.

## 시험 순서

1. 최신 패키지를 새 폴더에 압축 해제하고 실행합니다. 기존 JSON은 별도 보관한 뒤 지도에 불러옵니다.
2. 지도에서 보정한 카메라를 선택합니다. 저장된 시점은 `estimate / unvalidated`이며 실제 렌즈 높이는 미측정일 수 있습니다.
3. 같은 PC의 SSM **라이브** 화면을 한 카메라로 표시하고 `화면캡처.cmd`에서 전체 영상 영역을 선택합니다.
   이름을 해당 카메라로 기록하고 수집합니다. 다른 창으로 가리거나 최소화하면 수집이 중지됩니다.
4. **실시간 영상 → 지도에서 라이브 확인**을 누릅니다. 수집 영상과 시각·장수가 갱신되는지 확인합니다.
5. **추적 기준 원본 사진**에서 보정에 쓴 파일을 선택합니다. 저장된 SHA-256 및 픽셀 크기가 모두 일치해야 합니다.
   재저장·리사이즈한 파일은 다른 파일입니다. 원본 영상 크기를 유지하고 참조와 현재 화면의 가로세로 비율 차이는 2% 이하여야 합니다.
6. **수집 화면이 선택한 카메라의 라이브 영상과 일치함을 확인**을 직접 선택합니다. 수집 이름으로 자동 연결하지 않습니다.
7. **영상 방향 비교 시작**을 누릅니다. 처음에는 지도 갱신이 꺼져 있습니다. 처음 비교 모듈 준비는 최대 20초 기다립니다.
8. 독립 검증을 통과한 시점이 두 화면에서 연속으로 일치하면 방향·기울기·수평 화각 추정치가 표시됩니다.
9. 비교 결과를 확인한 뒤 **대응 검증 시 지도 시점 자동 갱신**을 켜면 브라우저 지도의 가상 시점만 갱신합니다.
   영상 패널 사용 중에는 수동 시점 조정 패널을 숨기고 잠가 두 기능이 같은 지도를 동시에 바꾸지 않게 합니다. 추정치를 지도 설정에 자동 저장하지 않습니다. 기준 수동 시점과 지리적 정합 오차를 그대로 포함합니다.
10. 화면 가림·만료·저대비·대응 실패 시 추정 표시와 지도 갱신을 해제합니다. 지도에 남은 마지막 시점은 현재 방향이 아닙니다.
    같은 세션에서 대응이 회복되면 두 화면 확인 후 재개합니다. 수집 세션/이름·선택 카메라 변경 시 확인을 다시 받아야 합니다.
    패널을 닫거나 브라우저 탭이 숨겨지면 비교를 중지합니다. 수집 도구 중지는 별도로 합니다.

SSM을 시험 목적으로 움직이지 않습니다. 정상 운영 중 자연스럽게 생기는 변화 또는 허가된 시험 자료를 관찰합니다.
수집 시각은 화면을 읽은 회사 PC 시각입니다. 원본 영상이 멈췄거나 재생 중인지 자동 판별하지 않으므로 SSM 상태를 직접 확인합니다.

## 추정과 미확인 처리

- 패키지에 고정 버전 OpenCV.js 4.12.0을 포함하고 Web Worker에서 ORB 특징점을 계산합니다. 최대 분석 변은 960px입니다.
  사진·실시간 프레임은 메모리에서 처리하며 분석 서버로 전송하거나 브라우저 저장소에 보관하지 않습니다.
- 상단 20%, 테두리, 중앙 커서 주변을 제외합니다. 이것은 구름·연기·영상 UI를 완전히 구분하는 검출기가 아닙니다.
- 양방향 이웃 대응과 비율 검사 후 가까운 중복 특징점을 제거합니다. 대응점 1/4을 RANSAC **이전**에 검증용으로 제외합니다.
- 계산 대응 24개 이상, 검증 대응 8개 이상, 각각 비율 45%/50% 이상을 요구합니다.
  계산점은 양쪽 영상에서 볼록껍질 면적 2%, 가로 25%, 세로 10% 이상으로 퍼져 있어야 합니다.
- 계산점만 이용해 고정된 기준 광선에서 방위각·기울기·화각을 계산합니다. 영상 중앙 주점·정사각 픽셀·roll=0을 가정합니다.
  계산 RMS 2px 이하, 검증 RMS 2.5px 이하, 최대 잔차 8px 이하, 조건수 1000 미만을 요구합니다. 픽셀 오차는 축소된 분석 영상 기준입니다.
- 기준 대비 방위각 변화 45°, 기울기 30°, 화각 비율 0.6~1.8 범위 안에서만 시험합니다.
  연속 두 결과의 방위각/기울기 차이 3° 이내, 화각 비율 차이 5% 이내일 때 추정을 표시합니다.
- 매번 고정 참조와 비교하므로 프레임 간 누적 추정은 하지 않습니다. 지형 겹침이 사라지면 새 현재 시점은 미확인입니다.
- 분석은 한 번에 한 프레임만 처리하며 대기열을 쌓지 않습니다. 분석 3.5초 초과 및 수집/추정 화면 4초 만료 시 미확인입니다.
  취소·수집 변경 전에 시작한 결과나 과거 지도 응답으로 새 상태를 덮어쓰지 않습니다.
- Bridge의 `directionStatus: unknown`, `automaticDirectionTrackingImplemented: false`는 서버가 실제 PTZ나 방향을 산출하지 않는다는 뜻입니다.
  이번 기능은 선택한 로컬 브라우저의 별도 추정 시험이며 중앙 방향 수신·다른 PC 공유는 구현하지 않습니다.

이 기준은 시안의 오인식 방지 조건이며 실제 방위/화재 위치 정확도를 보증하지 않습니다.
위치·고도·렌즈 왜곡·크롭·기준 시점 오차·회전축 이동·구름/나무 움직임 등은 잔여 오차와 실패 원인입니다.
큰 방향 변화나 시간대가 다른 야간 화면이 항상 대응되는 것은 아닙니다. 임계값을 통과시키려고 기준점을 바꾸거나 결과를 실제 PTZ로 취급하지 않습니다.

## 검증 범위

독립 OpenCV 카메라 투영으로 만든 **합성** 회전/줌 영상에서 실제 배포 Worker의 영상 대응과 수치 복원을 검사합니다.
검증점 독립성, 다른 영상·검은 영상 거절, 명시적 카메라 확인, 지도 갱신 기본 꺼짐, 가림·수집 변경·종료와 저장 설정 보존을 확인합니다.
현장 원본과 실제 보정값은 테스트/소스/패키지에 넣지 않습니다.
사용자 제공 야간 원본의 로컬 비공개 실험에서는 동일 사진의 대응은 성공했지만 서로 다른 두 시점은 대응 부족으로 미확인이었습니다.
회사 PC의 연속 입력 성능·지도 갱신·실제 방향 정확도는 이번 패키지로 후속 확인해야 합니다.
