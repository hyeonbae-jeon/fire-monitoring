# 로컬 영상 대응과 지도 시점 갱신 시험

수집되는 화면을 고정된 참조 사진과 비교합니다. 이 영상 대응 시험은 RTSP 스트림·PTZ 제어·외부 영상 전송을 사용하지 않습니다. 한화 JPEG 직접 수신 시험을 선택한 경우에도 동일한 참조 비교·검증 조건을 사용합니다. 별도 장비 PTZ 조회는 아래 설명과 실행 방법을 참고하세요.
이 기능은 **로컬 Windows 실행 패키지의 지도 모니터링 → 실시간 영상**에 있습니다. 공개 Pages에서는 회사 영상과 연결하지 않습니다.

## 장비 PTZ 근사 추종으로 진행

직접 JPEG와 장비 PTZ를 받는 경우 **지도 추종 방식 → 장비 PTZ 근사 추종**을 선택할 수 있습니다.
지리적 기준점의 정밀 정합이나 사진 대응 성공을 시작 조건으로 요구하지 않습니다. 설치 좌표는 그대로 사용합니다.

1. 로컬 지도에서 카메라를 선택하고 **실시간 영상 → 한화 카메라 직접 수신**으로 연결합니다. **장비 Pan·Tilt·Zoom 함께 조회**를 켭니다.
2. **지도 추종 방식 → 장비 PTZ 근사 추종**을 선택합니다. 현재 CCTV에 대응시킬 지도 방위각·기울기·화각·렌즈 높이를 입력합니다. 앞서 적용한 수동 가상 시점이 있으면 같은 카메라의 값을 시작값으로 사용합니다. 지면 고도 빈칸은 지도 자동 조회입니다.
3. 선택한 카메라와 현재 영상을 확인하고 **현재 PTZ를 기준으로 시험 추종 시작**을 누릅니다. 시작 순간의 장비 Pan/Tilt/Zoom과 입력한 지도 시점을 메모리에 연결합니다.
4. Pan 변화량을 방위각에 더하고 Tilt 변화량을 기울기에서 뺍니다. 북쪽 0°/360° 경계를 처리합니다. **장비 Zoom 배율로 화각도 근사**를 켜면 초점거리와 줌 배율이 비례한다고 가정해 화각을 계산합니다. 끄면 화각을 고정합니다.
5. **장비 추종 중지** 후 기준 시점을 다시 입력해 재시작하면 근사 방향을 조정할 수 있습니다. 정밀 검증을 위한 전방향 사진 수집은 필요하지 않습니다.

영상과 장비 값은 각각 4초 안의 최신 값이어야 합니다. 수신 만료·오류 때 지도 갱신을 멈추고 같은 세션에서 회복되면 재개합니다.
세션·이름·카메라 변경, 패널 닫기와 탭 숨김은 시험을 종료합니다. 저장된 기준이 있으면 재개 버튼을 사용하고, 없으면 현재 화면으로 기준을 잡습니다.
장비 이동 명령은 보내지 않습니다. 시작 기준과 결과는 지도 설정·JSON·브라우저 저장소에 자동 저장하지 않습니다.
현재 시험은 수평 화각 5~120°, 기울기 ±80° 범위이며 지원 범위를 벗어난 줌·각도에서는 갱신을 멈춥니다.
이 모드는 설치 축 기울기·줌별 렌즈 특성·기준 방향의 오차를 포함하는 운영자 설정 근사입니다. 실제 북쪽 기준 방향이나 산불 좌표의 정밀 보정을 완료했다는 뜻은 아닙니다.

## 카메라별 근사 기준 보관과 재개

추종 동작을 확인한 뒤 **근사 기준을 지도 설정에 반영**을 누릅니다. 기준은 시작 순간의 원래 Pan/Tilt/Zoom과 지도 각도·렌즈 높이·지면 고도·줌 근사 선택을 카메라별로 묶습니다. 저장 버튼을 누를 때 현재 움직인 PTZ로 기준을 바꾸지 않습니다.

**카메라·설정 → 중앙 지도 설정 저장**으로 로컬 Bridge에 보관하면 재실행할 때 읽어옵니다. 또는 **좌표 설정 다운로드**로 JSON을 보관해 다시 불러올 수 있습니다. ‘반영’만 누르고 종료하면 아직 파일에 보관되지 않은 상태입니다. 기존 설정 파일도 새 버전에서 그대로 읽습니다.

재실행 후 같은 카메라에 직접 JPEG/PTZ를 연결하고 **장비 PTZ 근사 추종 → 수신 영상이 선택한 카메라임을 확인 → 저장 기준으로 추종 재개**를 선택합니다. 카메라가 기준과 다른 방향·줌에 있어도 원래 기준과 현재 장비 값의 차이를 계산합니다. 연결과 지도 갱신을 자동으로 시작하지 않습니다.

실시간 영상 패널의 **추종할 설치 카메라**에서 다른 설치점을 선택하면 이전 영상 표시와 추종을 정리합니다. 선택한 카메라의 주소·계정으로 직접 수신을 시작하고 그 카메라의 기준을 사용하세요. 기준이 없으면 새 기준을 한 번 잡아 반영합니다. 한 번에 선택한 한 카메라를 추종합니다.

주소·ID/PW·조회 키·영상·세션 식별자는 근사 기준에 넣지 않습니다. 저장 형식의 `nativeTracking`은 수동 사진 보정 `orientation`과 별도이며 정확도 표시는 `approximate`입니다. 설치 좌표를 바꾸면 이전 근사 기준을 재사용하지 않습니다. 새 기준 형식의 중앙 저장·재개는 최신 실행 패키지가 필요합니다.

## 영상 대응 시험 순서

1. 최신 패키지를 새 폴더에 압축 해제하고 실행합니다. 기존 JSON은 별도 보관한 뒤 지도에 불러옵니다.
2. 지도에서 보정한 카메라를 선택합니다. 저장된 시점은 `estimate / unvalidated`이며 실제 렌즈 높이는 미측정일 수 있습니다.
3. 같은 PC의 SSM **라이브** 화면을 한 카메라로 표시하고 `화면캡처.cmd`에서 전체 영상 영역을 선택합니다.
   이름을 해당 카메라로 기록하고 수집합니다. 다른 창으로 가리거나 최소화하면 수집이 중지됩니다.
4. **실시간 영상 → 지도에서 라이브 확인**을 누릅니다. 수집 영상과 시각·장수가 갱신되는지 확인합니다.
5. **추적 기준 원본 사진**에서 보정에 쓴 파일을 선택합니다. 저장된 SHA-256 및 픽셀 크기가 모두 일치해야 합니다.
   재저장·리사이즈한 파일은 다른 파일입니다. 기준 사진의 해시 확인은 유지하지만, 현재 캡처의 가로세로 비율이 다르다는 이유만으로 비교를 막지 않습니다.
6. **수집 화면이 선택한 카메라의 라이브 영상과 일치함을 확인**을 직접 선택합니다. 수집 이름으로 자동 연결하지 않습니다.
7. **영상 방향 비교 시작**을 누릅니다. 처음에는 지도 갱신이 꺼져 있습니다. 처음 비교 모듈 준비는 최대 20초 기다립니다.
8. 독립 검증을 통과한 시점이 두 화면에서 연속으로 일치하면 방향·기울기·수평 화각 추정치가 표시됩니다.
9. 비교 결과를 확인한 뒤 **대응 검증 시 지도 시점 자동 갱신**을 켜면 브라우저 지도의 가상 시점만 갱신합니다.
   영상 패널 사용 중에는 수동 시점 조정 패널을 숨기고 잠가 두 기능이 같은 지도를 동시에 바꾸지 않게 합니다. 추정치를 지도 설정에 자동 저장하지 않습니다. 기준 수동 시점과 지리적 정합 오차를 그대로 포함합니다.
10. 화면 가림·만료·저대비·대응 실패 시 추정 표시와 지도 갱신을 해제합니다. 지도에 남은 마지막 시점은 현재 방향이 아닙니다.
    같은 세션에서 대응이 회복되면 두 화면 확인 후 재개합니다. 수집 세션/이름·선택 카메라 변경 시 확인을 다시 받아야 합니다.
    패널을 닫거나 브라우저 탭이 숨겨지면 비교를 중지합니다. 수집 도구 중지는 별도로 합니다.

**한화 카메라 직접 수신**을 선택하면 화면 캡처 대신 직접 받은 JPEG가 위 비교 절차에 입력됩니다. 연결 순서와 종료·계정 보관 범위는 [Windows 사용방법](windows-demo.md#한화-카메라-jpeg-직접-수신-시험)을 참고하세요.
장비 회전량과 영상 회전량을 대조할 때는 직접 수신의 **영상·PTZ 기준 묶음 저장**으로 두 시점을 같은 경로에서 저장합니다.
각 ZIP의 원본 이미지와 전후 PTZ·시각을 사용합니다. JPEG 요청 전후에 값이 안정됐다는 근거이며 센서 촬영 동시성을 보증하지 않습니다.

SSM을 시험 목적으로 움직이지 않습니다. 정상 운영 중 자연스럽게 생기는 변화 또는 허가된 시험 자료를 관찰합니다.
수집 시각은 화면을 읽은 회사 PC 시각입니다. 원본 영상이 멈췄거나 재생 중인지 자동 판별하지 않으므로 SSM 상태를 직접 확인합니다.

## 캡처 영역이 달라졌을 때

1. 보정에 사용한 기준 사진은 그대로 선택합니다. 잘리지 않은 새 원본으로 바꾸려면 그 원본으로 방향·화각 보정도 다시 저장해야 합니다.
2. 영상이 같은 방향·줌인 상태인데 화면 비율·잘림·늘어짐 때문에 대응이 실패하면 **영상 방향 비교 중지**를 누릅니다.
3. **기준 사진과 현재 영상의 방향·줌이 같음을 확인**에 직접 체크하고 **캡처 영역 맞추기**를 누릅니다.
   같은 카메라라는 것만으로는 충분하지 않습니다. 다른 방향·줌의 영상에서 이 작업을 하면 실제 변화를 캡처 차이로 흡수할 수 있습니다.
4. 공통 지형의 계산점·별도 검증점으로 캡처의 가로/세로 크기와 위치 차이를 계산합니다. 통과하면 **캡처 영역 보정 사용 중**이 표시됩니다.
5. **영상 방향 비교 시작**을 누릅니다. 이 캡처 변환은 이후 화면에서 고정해서 쓰며, 매 프레임 다시 학습하지 않습니다.
   후속 방향·줌 변화는 별도 방향·화각 모델의 검증을 통과해야 합니다. 지도는 캡처 변형을 제거한 기준 사진의 화면 비율로 표시합니다.
6. 수집을 다시 시작하거나 이름/카메라를 바꾸거나 패널을 닫으면 영역 보정이 해제됩니다. 같은 세션에서 픽셀 크기가 달라져도 기존 보정으로 지도 갱신을 하지 않습니다.
   같은 크기로 SSM 내부 영상 배치가 달라진 것은 자동 판별할 수 없으므로 **캡처 영역 보정 해제** 후 같은 시점에서 다시 맞춥니다.

캡처 영역을 픽셀 단위로 똑같이 맞출 필요는 없습니다. 공통 지형이 충분히 넓게 보여야 하며, 안개·가림·작은 일부 영역·과도한 늘어짐은 대응 실패가 될 수 있습니다.
영상만으로 캡처의 잘림과 일부 PTZ 변화를 항상 구분할 수 없으므로, 영역 맞추기는 사용자의 같은 방향·줌 확인이 필요합니다. 자동 PTZ 측정이나 기준 시점의 실제 정확도 검증은 아닙니다.
영역 보정값과 영상은 메모리에서만 처리하며 JSON·중앙 설정에 저장하지 않습니다. 최신 수집 영상과 공통 지형이 없으면 추정·지도 갱신을 하지 않습니다.

## 추정과 미확인 처리

- 패키지에 고정 버전 OpenCV.js 4.12.0을 포함하고 Web Worker에서 ORB 특징점을 계산합니다. 최대 분석 변은 960px입니다.
  사진·실시간 프레임은 메모리에서 처리하며 분석 서버로 전송하거나 브라우저 저장소에 보관하지 않습니다.
- 상단 20%, 테두리, 중앙 커서 주변을 제외합니다. 이것은 구름·연기·영상 UI를 완전히 구분하는 검출기가 아닙니다.
- 양방향 이웃 대응과 비율 검사 후 가까운 중복 특징점을 제거합니다. 대응점 1/4을 RANSAC **이전**에 검증용으로 제외합니다.
- 계산 대응 24개 이상, 검증 대응 8개 이상, 각각 비율 45%/50% 이상을 요구합니다.
  계산점은 양쪽 영상에서 볼록껍질 면적 2%, 가로 25%, 세로 10% 이상으로 퍼져 있어야 합니다.
- 계산점만 이용해 고정된 기준 광선에서 방위각·기울기·화각을 계산합니다. 영상 중앙 주점·정사각 픽셀·roll=0을 가정합니다.
  계산 RMS 2px 이하, 검증 RMS 2.5px 이하, 최대 잔차 8px 이하, 조건수 1000 미만을 요구합니다. 픽셀 오차는 축소된 분석 영상 기준입니다.
- 선택한 캡처 영역 보정은 계산점에서 축별 크기·위치 4개 값을 계산하고 검증점을 따로 검사합니다. 기준 분석 영상에서 계산 RMS 2px, 검증 RMS 2.5px, 최대 8px를 넘으면 적용하지 않습니다.
  보정 후 크기 배율은 축별 0.4~2.5 범위로 제한합니다. 영역 보정 사용 시 현재 분석 영상을 기준 크기로 정규화하고, 동일한 고정 변환으로 특징점 좌표를 복원합니다.
- 기준 대비 방위각 변화 45°, 기울기 30°, 화각 비율 0.6~1.8 범위 안에서만 시험합니다.
  연속 두 결과의 방위각/기울기 차이 3° 이내, 화각 비율 차이 5% 이내일 때 추정을 표시합니다.
- 매번 고정 참조와 비교하므로 프레임 간 누적 추정은 하지 않습니다. 지형 겹침이 사라지면 새 현재 시점은 미확인입니다.
- 분석은 한 번에 한 프레임만 처리하며 대기열을 쌓지 않습니다. 분석 3.5초 초과 및 수집/추정 화면 4초 만료 시 미확인입니다.
  취소·수집 변경 전에 시작한 결과나 과거 지도 응답으로 새 상태를 덮어쓰지 않습니다.
- Bridge의 `directionStatus: unknown`, `automaticDirectionTrackingImplemented: false`는 지리적 방향의 자동 산출·지도 연동이 없다는 뜻입니다.
  한화 직접 수신에서는 별도 선택으로 장비의 원시 Pan/Tilt/Zoom을 읽을 수 있으나 설치 방위·기울기·줌별 화각은 아직 미보정입니다.
  영상 대응은 선택한 로컬 브라우저의 별도 추정 시험이며 중앙 방향 수신·다른 PC 공유는 구현하지 않습니다.

이 기준은 시안의 오인식 방지 조건이며 실제 방위/화재 위치 정확도를 보증하지 않습니다.
위치·고도·렌즈 왜곡·크롭·기준 시점 오차·회전축 이동·구름/나무 움직임 등은 잔여 오차와 실패 원인입니다.
큰 방향 변화나 시간대가 다른 야간 화면이 항상 대응되는 것은 아닙니다. 임계값을 통과시키려고 기준점을 바꾸거나 결과를 실제 PTZ로 취급하지 않습니다.

## 검증 범위

독립 OpenCV 카메라 투영으로 만든 **합성** 회전/줌 영상에서 실제 배포 Worker의 영상 대응과 수치 복원을 검사합니다.
검증점 독립성, 다른 비율의 투영, 비대칭 잘림·늘어짐을 포함한 고정 캡처 보정 후 움직임 복원, 다른 영상·검은 영상 거절, 같은 시점의 명시적 확인, 지도 갱신 기본 꺼짐, 가림·수집 변경·종료와 저장 설정 보존을 확인합니다.
현장 원본과 실제 보정값은 테스트/소스/패키지에 넣지 않습니다.
사용자 제공 야간 원본의 로컬 비공개 실험에서는 동일 사진의 대응은 성공했지만 서로 다른 두 시점은 대응 부족으로 미확인이었습니다.
회사 PC의 연속 입력 성능·지도 갱신·실제 방향 정확도는 이번 패키지로 후속 확인해야 합니다.

2026-10-22 사용자 PC에서 숨은벽 직접 JPEG의 지속 수신과 별도 SUNAPI 현재 PTZ 조회의 값 반환을 확인했습니다.
장비 각도 자동 조회는 [실행 방법](windows-demo.md)에 따라 별도 시험합니다.
원시 Pan을 곧바로 북쪽 기준 방위각으로 사용하지 않습니다. 지리적 보정과 다른 시점의 독립 검증은 후속 단계입니다.
