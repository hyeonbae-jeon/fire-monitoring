# FIREWATCHER 온라인 문자 수신 경로 검토

확인일: 2026-10-30, 한국시간. 온라인 전용번호를 먼저 확인하고, 적합한 서비스가 없을 때 휴대폰 자동전달을 검토한다.

## 사용자 자료에서 확인한 사항

- 알림은 일반 문자(SMS·LMS·MMS 계열)로 수신한다. 카카오 알림톡이 아니다.
- 예시 문자 본문은 연기 발생 안내와 개별 알림 링크를 포함한다. 본문만으로 대상 카메라를 식별할 수 없다.
- 사용자는 개인 PC에서도 알림 링크가 열린다고 확인했다. 알림 페이지에는 FIREWATCHER, 카메라명, 감지 시각, 지도, 감지 이미지가 보인다.
- 관리 페이지의 접속 문제는 사용자가 VPN 때문이라고 확인했다. 문자 수신을 위해 회사 PC에서 코드를 작성해야 하는 것은 아니다.
- 알림 페이지의 HTML/API 계약은 아직 제공받지 않았다. 링크의 각 경로 조각을 이벤트 ID나 사용자 ID라고 단정하지 않는다.

## 조사 결과와 한계

이 실행 환경에서는 공개 검색과 업체 공식 사이트의 HTTPS 조회가 프록시 단계에서 403으로 차단됐다.
따라서 현재 상품, 국내 번호 발급 가능 여부, 수신 API 규격, 개인 가입 조건과 요금을 공식 자료로 확인하지 못했다.
번호 발급, 서비스 가입, 결제, 업체 문의 발송과 실제 문자 수신 시험은 수행하지 않았다.
**확인된 공급업체가 아직 없다는 뜻이며, 국내 온라인 수신 서비스가 불가능하다는 판정은 아니다.**

검토할 상품 유형은 전용번호를 제공하는 MO(문자 수신) 서비스 또는 수신함 조회 API를 제공하는 번호 서비스다.
일반 문자 발송 API의 배달 결과 콜백을 외부 문자를 받는 수신 API로 취급하지 않는다.
050·070 계열 번호가 후보인 경우 FIREWATCHER가 해당 번호로 발송 가능한지도 별도로 확인한다. 아직 번호 제한은 확인하지 않았다.

공개 코드 검색에서 `mtonet.co.kr/pages/mo`, `/pages/050service`라는 안내 주소의 단서를 찾았지만,
그 자료 자체도 공식 규격을 확인하지 못했다고 명시한다. 해당 상품이나 API를 검증한 근거로 사용하지 않는다.

## 서비스 선정 조건

| 항목 | 확인할 내용 |
| --- | --- |
| 전용 수신번호 | 휴대폰 단말 없이 유지 가능한 국내 번호인지, 번호 종류와 장기 사용 조건 |
| 송신원 호환 | FIREWATCHER의 국내 기업 발신 SMS/LMS가 실제 도착하는지 |
| 본문 보존 | 한글·줄바꿈·장문과 알림 URL 전체가 원문대로 전달되는지 |
| 조회 방식 | 수신 내역 조회 API 또는 HTTPS 웹훅의 공식 문서와 인증 방법 |
| PC 종료 중 수신 | 메시지 보관 기간, 누락분 조회, 웹훅 재전송과 중복 식별 방식 |
| 운영 비용 | 개인/사업자 가입 조건, 개통비, 월 고정비, 수신·API 이용료 |

개인 PC가 필요할 때 실행되는 사용 방식에는 보관된 수신함을 API로 조회할 수 있는 상품이 편리하다.
웹훅만 제공한다면 인터넷에서 접근 가능한 수신 주소와 PC 종료 중 보관·재전송 방법이 필요하다.
아직 어느 방식도 실제 공급업체 계약으로 확인하지 않았으므로 수신 서버나 수신 어댑터를 추가하지 않는다.

## 업체에 전달할 문의문

> 국내 산불감시 시스템이 발송하는 일반 한글 문자와 장문문자(LMS)를 전용번호로 받아 Windows 모니터링 프로그램에 연동하려고 합니다.
> 문자에는 감지 알림 페이지 링크가 포함됩니다. 휴대폰 단말 없이 사용할 수 있는 국내 전용 수신번호를 제공하나요?
> 국내 기업 발신 문자를 수신할 수 있고 한글 본문·줄바꿈·URL 전체를 API로 조회하거나 HTTPS 웹훅으로 전달받을 수 있나요?
> PC가 꺼져 있는 동안 받은 문자도 보관했다가 조회할 수 있는지, 보관 기간·메시지 ID·수신 시각·중복/재전송 규격을 알려주세요.
> 지원 번호 종류, 개인/사업자 가입 조건, 공식 수신 API 문서, 개통비·월 고정비·수신/API 이용료도 부탁드립니다.

## 수신 경로를 확보한 뒤 구현할 범위

1. 공식 규격으로 실제 문자 한 건을 수신하고 본문·링크가 보존되는지 확인한다.
2. 받은 알림 링크를 추출하고, 운영자가 지정한 알림 서버의 읽기 전용 페이지만 조회한다.
3. 실제 HTML 또는 JSON 응답을 확인해 카메라명·감지 시각·이미지를 읽는 어댑터를 작성한다. 캡처 화면만으로 응답 필드를 만들어내지 않는다.
4. 확인된 동일 카메라에 연결하고 이벤트 중복과 PC 재시작 후 누락분을 처리한다. 현재 PTZ를 과거 감지 시점의 방향으로 간주하지 않는다.
5. 인증된 AI 감지 알림 화면에 표시한다. 공급업체의 알림 해제·삭제 기능은 별도 요청 없이 호출하지 않는다.

현재 프로그램에는 온라인 번호 발급 또는 SMS 수신 연동이 구현되어 있지 않다. 기존 알림 시안과 보정 기본값은 이 조사로 변경하지 않는다.
